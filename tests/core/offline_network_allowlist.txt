# Functions in app/ and core/ that open a network connection without asking
# core.offline themselves (tests/core/test_offline_activity.py enforces it).
#
# Every other function that calls urlopen, requests, httpx, aiohttp,
# websockets, socket.socket, create_connection, http.client, a Hugging Face
# download or a urllib opener must call is_offline, require_online, refused,
# skipped, url_stays_local, ensure_online or _may_go_online in its own body.
# An entry here needs a reviewer's sign-off: name the caller that asks first,
# or why the call cannot leave this computer.
#
# Format: <path>::<qualified function name>  <reason>
#
# Known limits of the scan: a network call on an object stored in a variable
# (s = requests.Session(); s.get(...)) is not seen, and a check anywhere in
# the function counts, even after the call.
