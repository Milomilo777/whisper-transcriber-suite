ホーム › YouTube をテキスト化

YouTube 動画をテキストに文字起こし — 無料でオフライン対応

一度インストールすれば使える無料デスクトップアプリ（Windows、macOS、Linux 対応）。動画のダウンロードにはインターネットが必要ですが、文字起こし自体はお使いの PC 上で実行されます。

YouTube 動画をテキスト化するには、リンクを「動画のダウンロード」タブに貼り付け、テキスト形式を選択し、「ダウンロード後に文字起こし」にチェックを入れて「ダウンロード」を押します。アプリはオープンソースのダウンローダー yt-dlp で動画を取得し、お使いの PC 上で Whisper（音声認識モデル）を使って文字起こしを行い、TXT、DOCX、PDF、または SRT 形式の文字起こしを保存します。

インストールせずに試す？ ブラウザで試す：短いファイル（最長10分）をあなたの端末で文字起こしする無料ページです。アップロードも登録も不要。長いファイルは下のアプリで処理できます。

無料アプリをダウンロード

はじめる前に

インストーラーは必ず 公式の GitHub リリースページ（ホームページからリンクされています）から入手してください。コード署名がされていないため、初回起動時に Windows の警告が表示される場合があります（「詳細情報」>「実行」を選択）。動作要件: インストールガイド。

YouTube 動画を文字起こしする方法

  1. 初回起動時のみ。「クイック スタート」画面で使用言語と 高速 または 最高品質 の選択を求められます。音声モデルは初回利用時に一度だけダウンロードされます。
  2. 「動画のダウンロード」タブを開き、YouTube のリンクを動画リンクに貼り付けます。形式や字幕はアプリが自動で調べます。
  3. モードを選択します。音声 は音声のみを保存するため、文字起こしだけが必要な場合にファイルサイズが小さく高速です。音声と動画 は映像も一緒に保存します。
  4. 任意：フォームの下のその他のオプションを開き、時間範囲（任意）で一部分だけをダウンロードして文字起こしできます。形式は H:MM:SS で、両方のボックスが 0:00:00 なら動画全体です。範囲を設定するとその他のオプションは自動で開きます。
  5. ダウンロードする前にファイル形式を選びます。文字起こしタブに切り替え、詳細設定…をクリックして、出力形式でTXT（または DOCX、PDF）にチェックを入れます。初期設定は SRT と JSON で、これは字幕であり、プレーンテキストではありません。JSON はチェックしたままにしてください。アプリが文字起こしビューアーを開くために使うファイルです。そのタブで選んだ言語と精度レベルは、ダウンロードにも適用されます。
  6. 「動画のダウンロード」タブに戻り、「ダウンロード後に文字起こし」にチェックを入れて、ダウンロード をクリックします。
  7. 進捗を確認します。 テーブルの行が進み、文字起こしキュー タブに速度と残り時間が表示されます。完了すると、文字起こしファイルは元データと同じ場所に保存され、「文字起こし」タブの 前回の結果 カードから 開く、文字起こしを表示、共有用ページを保存 を利用できます。

動画にすでに字幕がある場合の高速な方法

検索した動画にすでに字幕がある場合、リンクの下に緑色のラインで 字幕が利用可能 と表示され、代わりに字幕を使う ボタンが表示されます。メディアのダウンロードと文字起こしをスキップし、字幕を取得して選択した形式に変換します。数分ではなく数秒で完了しますが、新たに Whisper で文字起こししたものではなく、既存の字幕をそのまま取得することになります。ダウンロード後に文字起こし にチェックが入っている場合、どちらを使用するかアプリから確認され、回答を記憶させることもできます。

ログインが必要なその他のサイトや動画

同じダウンローダーが対応するサイトなら、どこでも同じ方法で使えます。Instagram、Facebook、TikTok のストーリー、年齢制限のある YouTube 動画など、アカウントが必要な動画は、フォームの下のその他のオプションを開き、ログイン Cookieでお使いのブラウザを選びます。アプリはこのパソコン上のそのブラウザのログイン情報を読み取り、そのサイトからダウンロードするときだけ使います。他の場所には送信されません。制限付きの動画すべてで使えるとは限りません。

知っておくと便利なこと

  • 接続がなければダウンロードできません。 ファイル → オフラインで作業 がオンになっている間はリンクの取得が行われないため、リンクを貼り付ける前にオフにしてください。
  • YouTube には専用のヘルパーが必要です。 リンク状態の横に YouTube ヘルパーをインストール ボタンが表示されたら、一度クリックしてください。これがないと YouTube の一部またはすべての形式が取得できず、ダウンロードに失敗することがあります。ダウンローダーが古いためにダウンロードに失敗した場合は、更新する バーが表示されます。

よくある質問

本当に無料ですか？

はい。無料でオープンソースであり、アカウント登録やサブスクリプション、分単位の料金も一切かかりません。

動画や文字起こしがどこかにアップロードされることはありますか？

デフォルトのエンジンではアップロードされません。Whisperはお使いのコンピューター上で動作し、動画サイトからのダウンロード時のみネットワークを使用します。2つのクラウドエンジンも用意されていますが、ご自身で有効にしない限りオフのままです。

字幕のない動画や、他言語の動画も文字起こしできますか？

はい。Whisperは音声を直接聞き取るため、字幕は不要です。話されている言語を選択するか、自動のままにします。出力: 英語への翻訳は英語以外の音声を英語のテキストに変換します。デフォルトではオフになっており、すべてのエンジンやモデルで動作するわけではありません。

長い動画の一部だけを文字起こしすることはできますか？

はい。「動画のダウンロード」タブのその他のオプションを開き、時間範囲（任意）に H:MM:SS で開始と終了を入力します。その部分だけがダウンロードされ、ダウンロード後に文字起こしにチェックを入れていれば文字起こしもされます。

プレイリスト全体を貼り付けることはできますか？

いいえ。1つのタスクにつき動画1本です。プレイリスト内からコピーしたリンクでも、リスト全体ではなくその動画のみがダウンロードされます。
