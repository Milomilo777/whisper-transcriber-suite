仕組み

お使いのコンピューター上で動作。音声データは手元にとどまります。

文字起こしはお使いのコンピューター上で実行されます。音声データがアップロードされるのは、2つのオプションであるクラウドエンジンのいずれかを有効にした場合のみです。また、文字起こしテキストが外部に送信されるのも、ご自身でリモートAIモデルを接続した場合に限られます。

  1. 01

    ファイルをドロップ、またはリンクを貼り付け

    ローカルディスク上の音声や動画、またはyt-dlpが取得できるあらゆるメディアに対応。メインプロセスで動作するTkインターフェースにより、瞬時にジョブがキューに追加されます。

  2. 02

    専用ワーカーがモデルを保持

    すべてのジョブは独立した常駐ワーカーサブプロセスで実行されます。Whisperをメモリ上に保持し、改行区切りのJSONで進捗をストリーミング送信するため、ウィンドウがフリーズすることはありません。

  3. 03

    文字起こし結果は元のファイルと同じ場所に保存

    ワーカーごとのトークンとハートビートにより確実なルーティングを維持し、ワーカーが応答しなくなった場合もアプリ全体が停止することなく異常を検知できます。

OpenAIのWhisper音声認識モデルをベースに構築され、faster-whisper、whisper.cpp、またはNVIDIA Parakeetを通じてローカルで実行。メディア処理にはyt-dlpとFFmpegを採用しています。

macOS — 1行インストール

ターミナルに貼り付けるだけです。

お使いの Mac に適したビルド（macOS 14+ では Apple Silicon、それ以外では Rosetta 経由の Intel）をダウンロードし、アプリを Applications にコピーして開きます。curl で取得したファイルは隔離されないため、「開発元が未確認」の警告をクリックしてやり過ごす必要もありません。

A=x64; [ "$(uname -m)" = arm64 ] && [ "$(sw_vers -productVersion | cut -d. -f1)" -ge 14 ] && A=arm64; curl -fL -o /tmp/wts.dmg "https://github.com/Milomilo777/whisper-transcriber-suite/releases/download/v2.2.0/WhisperTranscriberSuite-v2.2.0-macOS-$A.dmg" && hdiutil attach -nobrowse -quiet -mountpoint /tmp/wts-dmg /tmp/wts.dmg && cp -R "/tmp/wts-dmg/Whisper Transcriber Suite.app" /Applications/ && hdiutil detach -quiet /tmp/wts-dmg && rm /tmp/wts.dmg && open "/Applications/Whisper Transcriber Suite.app"

FAQ

よくある質問

他にご不明な点がありますか？GitHub Discussions でご質問ください。

Whisper Transcriber Suite は無料ですか？

はい。BSD-3-Clause ライセンスで提供されており、サブスクリプションや分単位の利用料は一切かかりません。Whisper モデル自体は初回起動時に一度ダウンロード（約 1〜3 GB）されますが、それ以降はインターネット接続なしで文字起こしが可能です。

音声や動画がどこかにアップロードされることはありますか？

いいえ、デフォルトではありません。すべての標準バックエンド — faster-whisper、whisper.cpp、NVIDIA Parakeet — はお使いの端末上でローカルに実行されます。2つのバックエンド（クラウド Gemini-API バックエンドと Google Cloud Speech-to-Text）はオプトイン方式であり、Advanced → Backend でご自身で有効にしない限りオフのままです。使用統計（音声やファイル名は収集されません）はデフォルトで有効ですが、ヘルプ → 使用統計 でオフにできます。アプリは新しいバージョンの有無を1日1回 GitHub で確認しますが、ファイル → オフラインで作業 を有効にすれば、すべてのネットワーク通信を停止できます。

どのプラットフォームで動作しますか？

Windows、macOS、Linux です。公開されているダウンロードファイルには、Windows インストーラー、Windows ポータブル ZIP、macOS DMG があります。Linux ではソースから実行します。

どのような文字起こし形式を出力できますか？

srt vtt ass tsv txt json lrc md docx pdf、さらに oTranscribe、ELAN、InqScribe、Express Scribe。

誰が話しているかを識別（ラベル付け）できますか？

はい — オプションの話者分離（「話者を識別」）に対応し、単語単位のタイムスタンプや時間範囲の切り出しが可能です。

マイクからのライブ音声やシステム音声を文字起こしできますか？

はい、「Live」タブから可能です — マイクやシステム音声を、そのままリアルタイムで文字起こしできます。

YouTube などのオンライン動画をダウンロードして文字起こしできますか？

はい、yt-dlp が対応するあらゆるサイトに対応しており、ダウンロード完了後に自動で文字起こしするオプションもあります。

文字起こしの要約、アクションアイテムの抽出、内容についての質問への回答はできますか？

はい、文字起こしビューアにあるオプションの「AI ツール」タブから利用可能です — 要約、アクションアイテム、質問、そしてセグメントごとに翻訳して2言語併記の .srt を書き出す機能が含まれます。デフォルトではオフになっています。

声をクローンして新しいテキストを話させることはできますか？

はい、オプションの「声のクローン」タブから利用でき、完全にお使いのコンピューター上で動作する OmniVoice (Apache-2.0) を使用します。デフォルトではオフになっており、インストール時にオプトインできます。なお、参照音声をクローンする権限があることを確認する必要があります。

Whisper API を直接呼び出すのとどう違いますか？

デフォルトでは faster-whisper を使ってモデルをローカルで実行するため、分単位の API 費用は発生せず、音声が端末の外に出ることもありません — 2つのクラウドバックエンドのいずれかを明示的に有効にした場合を除きます。

すべてのコンピューターにインストールすることなく、同一ネットワーク上の複数人で利用できますか？

はい — Web/LAN アクセスモードにより、このコンピューターをネットワーク上の他のデバイスから利用できる文字起こしページにすることができます。

バージョン 2.2 の新機能は？

精度レベルが文字起こしタブのエンジン・モデル選択に代わります。高速・バランス・最高から選ぶだけで、言語とパソコンに合ったモデルをアプリが選び、新規インストールでは Large v3 Turbo から始まります。あまり使わない設定はその他のオプションにまとめました。ペルシア語、中国語、日本語、ドイツ語、タイ語、スウェーデン語、ヘブライ語には、その言語専用のモデルが用意されます。Web / LAN アクセスタブには QR コードが表示され、同じ Wi-Fi のスマホから録音を送れます。Windows ではペルシア語・アラビア語・ヘブライ語向けにウィンドウが左右反転し、2言語が混ざった音声は試験的オプションとして使えます。ダウンロードのフォームもコンパクトになりました。42のインターフェース言語がすべてそろい、35件の不具合を修正しました。サイトには、短いファイルをブラウザで文字起こしできるページもあります。バージョン 2.1 では42言語のインターフェース、確実な話者ラベル、より安全な保存、バージョン 2.0 ではキューの速度と残り時間、リンクからの字幕付き動画、1つのオフライン Web ページとしての文字起こし、確認できる「オフラインで作業」モード、英語への翻訳が加わりました。2.2 の新機能と変更履歴もご覧ください。

動画リンクから字幕付き動画を作成できますか？

はい。「動画のダウンロード」タブで 字幕付き動画を作成 にチェックを入れると、アプリが動画をダウンロードし、Whisper で文字起こしを行い、ffmpeg で字幕を焼き付けて、動画名に -subbed.mp4 を付けたファイルを生成します。ダウンロードした動画と文字起こしデータは保持され、既存の -subbed.mp4 が上書きされることはありません。

アプリをネットワークから完全に切り離した状態に保つことはできますか？

はい。ファイル → オフラインで作業 を選択すると、アップデート確認、使用統計、モデルのダウンロード、リモート AI プロバイダーへの通信が停止します。このモードがオンの間は、ウィンドウ下部のステータス行で接続が開かれているかどうかが表示され、今すぐオフラインを確認 でテスト接続が拒否される様子を確認できます。オフの場合でも、アプリがネットワークに接続するのは、起動時のオンライン設定、毎日のアップデート確認、使用統計（ヘルプ → 使用統計 でオフに設定可能）、およびユーザーが開始したダウンロード時のみです。

プロジェクトへはどのように問い合わせればよいですか？

バグ報告や機能リクエストは GitHub Issues へ、質問は Discussions へ、その他の要件はメールでお送りください（アドレスは お問い合わせセクション でリクエストに応じて表示されます）。セキュリティに関する報告は、GitHub の非公開の脆弱性報告機能をご利用ください。
