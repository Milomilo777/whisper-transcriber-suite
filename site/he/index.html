macOS — התקנה בשורה אחת

הדבק לטרמינל. זהו.

מוריד את הבנייה הנכונה עבור ה-Mac שלך (Apple Silicon ב-macOS 14+, אחרת Intel דרך Rosetta), מעתיק את האפליקציה אל Applications ופותח אותה. קבצים שמובאים על ידי curl אינם בהסגר, כך שאין אזהרת "מפתח לא מזוהה" שצריך ללחוץ כדי לעבור.

A=x64; [ "$(uname -m)" = arm64 ] && [ "$(sw_vers -productVersion | cut -d. -f1)" -ge 14 ] && A=arm64; curl -fL -o /tmp/wts.dmg "https://github.com/Milomilo777/whisper-transcriber-suite/releases/download/v2.1.0/WhisperTranscriberSuite-v2.1.0-macOS-$A.dmg" && hdiutil attach -nobrowse -quiet -mountpoint /tmp/wts-dmg /tmp/wts.dmg && cp -R "/tmp/wts-dmg/Whisper Transcriber Suite.app" /Applications/ && hdiutil detach -quiet /tmp/wts-dmg && rm /tmp/wts.dmg && open "/Applications/Whisper Transcriber Suite.app"

מעדיפים את הדרך הרגילה? פתחו את .dmg וגררו את האפליקציה אל Applications; ההפעלה הראשונה תדרוש לחיצה ימנית → Open (macOS 14 ומטה) או System Settings → Privacy & Security → Open Anyway (macOS 15+).

כל גרסה, עם הערות, נמצאת ב-GitHub Releases. מדריך התקנה.

שאלות נפוצות

משהו אחר על דעתכם? שאלו ב-GitHub Discussions.

האם Whisper Transcriber Suite חינמי?

כן. הוא מורשה ב־BSD-3-Clause, ללא מנוי וללא עלות לדקה. מודל Whisper עצמו מורד פעם אחת (כ־1-3 ג'יגה־בייט) בהפעלה הראשונה; לאחר מכן, התמלול פועל ללא חיבור לאינטרנט.

האם הוא מעלה את השמע או הווידאו שלי לאיזשהו מקום?

לא, לא כברירת מחדל. כל backend ברירת המחדל — faster-whisper, whisper.cpp, NVIDIA Parakeet — פועל מקומית במחשב שלך. שני backends הם אופציונליים בלבד (backend ענן של Gemini-API, ו-Google Cloud Speech-to-Text), ושניהם נשארים כבויים עד שתפעילו אותם בעצמכם ב-Advanced → Backend. סטטיסטיקת שימוש (ללא אודיו, ללא שמות קבצים) מופעלת כברירת מחדל וניתנת לכיבוי תחת עזרה → סטטיסטיקת שימוש, האפליקציה בודקת ב-GitHub פעם ביום לגרסה חדשה, ו-File → עבודה ללא חיבור עוצר את כל השימוש ברשת.

באילו פלטפורמות הוא פועל?

Windows, macOS ו־Linux. ההורדות הזמינות הן תוכנית התקנה ל־Windows, קובץ ZIP נייד ל־Windows, ו־DMG ל־macOS; Linux פועל מקוד המקור.

אילו פורמטי תמלול הוא יכול לייצר?

srt vtt ass tsv txt json lrc md docx pdf, בתוספת oTranscribe, ELAN, InqScribe ו-Express Scribe.

האם הוא יכול לתייג מי מדבר?

כן — פילוח דוברים אופציונלי ("זהה דוברים"), עם חותמות זמן לכל מילה וחיתוך טווחי זמן.

האם הוא יכול לתמלל מיקרופון חי או שמע מערכת?

כן, מלשונית Live — מיקרופון או אודיו מערכת, מתומלל בזמן אמת.

האם הוא יכול להוריד ולתמלל סרטונים מקוונים, למשל מ־YouTube?

כן, כל אתר ש־yt-dlp תומך בו, עם שלב תמלול אופציונלי בסיום ההורדה.

האם הוא יכול לסכם תמלול, לחלץ פריטי פעולה, או לענות על שאלות לגביו?

כן, דרך לשונית כלי בינה מלאכותית האופציונלית במציג התמליל — סיכום, פריטי פעולה, שאל שאלה, ומעבר תרגום לכל קטע שכותב .srt דו-לשוני. זה כבוי כברירת מחדל.

האם הוא יכול לשבט קול ולגרום לו לומר טקסט חדש?

כן, דרך לשונית שיבוט הקול שלך האופציונלית, באמצעות OmniVoice (Apache-2.0) לחלוטין במחשב שלך. כבוי כברירת מחדל; בחרו להפעיל בזמן ההתקנה, ועליכם לאשר שיש לכם הרשאה לשכפל את הקול המקורי.

כיצד זה שונה מקריאה ישירות ל־Whisper API?

הוא מפעיל את המודל מקומית דרך faster-whisper כברירת מחדל, כך שאין עלות API לדקה ואף אודיו לא עוזב את המחשב שלך — אלא אם כן תבחרו במפורש באחד משני backends הענן.

האם מספר אנשים באותה רשת יכולים להשתמש בו מבלי להתקין אותו על כל מכשיר?

כן — מצב גישה Web/LAN הופך את המחשב הזה לדף תמלול שבו יכולים להשתמש שאר המכשירים ברשת.

מה חדש בגרסה 2.1?

תפריטים, כפתורים והודעות מגיעים ב-42 שפות (מתורגמות במכונה ומסומנות ככאלה); תוויות דוברים מגיעות עד סוף הקלטות ארוכות וניתן להגדיר כמה אנשים מדברים; תמלילים, ייצוא וכתוביות נכתבים במלואם לדיסק לפני שהם מחליפים את הקובץ הישן; תכונות מקוונות עובדות בכל Mac. גרסה 2.0 הוסיפה את מהירות התור והזמן שנותר, וידאו עם כתוביות מקישור, תמלילים כדף אינטרנט לא מקוון אחד, מצב עבודה ללא חיבור שניתן לסמן ותרגום לאנגלית. ראו את מה חדש ב-2.1 ואת יומן השינויים.

האם הוא יכול להפוך קישור וידאו לווידאו עם כתוביות?

כן. בלשונית הורדת סרטונים, סמנו את צור וידאו עם כתוביות: האפליקציה מורידה את הסרטון, מתמללת אותו עם Whisper וצורבת את הכתוביות עם ffmpeg, ומייצרת קובץ בעל שם זהה לסרטון עם -subbed.mp4. ההורדה והתמליל נשמרים, וקובץ -subbed.mp4 קיים לעולם לא מוחלף.

האם אוכל להשאיר את האפליקציה מנותקת מהרשת לחלוטין?

כן. File → עבודה ללא חיבור עוצר את בדיקת העדכונים, את סטטיסטיקת השימוש, את הורדות המודלים ואת ספקי ה-AI המרוחקים. כשהוא מופעל, שורה בתחתית החלון מציינת אם חיבור פתוח, ו-אמת מצב לא מקוון עכשיו מציג חיבורי בדיקה שנדחים. כשהוא כבוי, האפליקציה יוצרת קשר עם הרשת רק עבור הגדרות הרשת שלה בעלייה, בדיקת העדכונים היומית, סטטיסטיקת שימוש (שניתנת לכיבוי תחת עזרה → סטטיסטיקת שימוש) והורדות שתתחילו.
