New in 2.3

What's new in 2.3. Your language, your Mac, your other apps.

A language button above the tabs, Whisper on the GPU of M-series Macs, transcripts sent to Obsidian or n8n, a safer built-in server and more than 107 bugs fixed. Below them, what 2.2, 2.1 and 2.0 added.

2.3 · All platforms

A language button

A globe button above the tabs shows the language the app runs in and opens a list of every language by its own name. Persian, Arabic and Hebrew now work on macOS too, and Persian and Arabic on Linux.

2.3 · macOS

Whisper on the Mac's GPU

On a Mac with an M-series chip, Whisper runs on the graphics chip through Apple's MLX, chosen for you when the model has an MLX version. Pick Faster-Whisper in the Engine list to turn it off.

2.3 · All platforms

Send transcripts to other apps

When a job finishes, the transcript can also be saved as a note in your Obsidian vault, and a short message can go to a web address such as an n8n webhook. Turn them on in Advanced → App behaviour.

2.3 · All platforms

A safer built-in server

Links sent to the Web / LAN server download through a guarded path that refuses addresses inside your network, and wrong passwords are slowed down after five tries.

2.3 · All platforms

Downloads leave your files alone

If a file with the same name is already in the folder, the new download is saved as Title (1) and the old file is never touched. Very long titles no longer make a download fail.

2.3 · All platforms

Live captions that survive a crash

Every finished sentence in the Live tab is written to disk before it appears, so a crash or power cut before you save no longer loses it. On a Mac, the Live tab explains the microphone permission the first time it listens.

2.3 · All platforms

Groq in one click

Press Use Groq in Advanced → AI and add your free Groq key for summaries and translations from a fast online model. Persian Best quality now uses a model trained for Persian.

Jak to działa

Działa na Twoim komputerze. Twoje nagrania tam pozostają.

Transkrypcja odbywa się na Twoim własnym komputerze. Twoje nagrania są przesyłane tylko wtedy, gdy włączysz jeden z dwóch opcjonalnych silników w chmurze, a tekst transkrypcji opuszcza komputer wyłącznie wtedy, gdy samodzielnie połączysz zdalny model AI.

  1. 01

    Upuść plik lub wklej link

    Audio lub wideo z dysku albo cokolwiek, co może pobrać yt-dlp. Interfejs Tk działa w głównym procesie i błyskawicznie dodaje zadanie do kolejki.

  2. 02

    Proces roboczy przechowuje model

    Każde zadanie działa w osobnym, długo działającym podprocesie roboczym, który utrzymuje Whisper w pamięci i przesyła postęp w formacie JSON rozdzielanym znakami nowej linii — dzięki czemu okno nigdy się nie zawiesza.

  3. 03

    Transkrypcja trafia tuż obok Twojego pliku

    Indywidualny token dla każdego procesu roboczego oraz sygnał heartbeat zapewniają niezawodny routing i pozwalają aplikacji wykryć zawieszony proces roboczy, zamiast blokować cały program.

Oparte na opracowanym przez OpenAI modelu rozpoznawania mowy Whisper, uruchamiane lokalnie za pośrednictwem faster-whisper, whisper.cpp lub NVIDIA Parakeet, z wykorzystaniem yt-dlp i FFmpeg do obsługi multimediów.

Instrukcja kompilacji ze źródeł

macOS — instalacja jednym poleceniem

Wklej do Terminala. To wszystko.

Pobiera odpowiednią wersję dla Twojego Maca (Apple Silicon na macOS 14+, w przeciwnym razie Intel przez Rosetta), kopiuje aplikację do Applications i ją otwiera. Pliki pobrane przez curl nie są objęte kwarantanną, więc nie ma ostrzeżenia o „niezidentyfikowanym deweloperze”, które trzeba by przeklikać.

A=x64; [ "$(uname -m)" = arm64 ] && [ "$(sw_vers -productVersion | cut -d. -f1)" -ge 14 ] && A=arm64; curl -fL -o /tmp/wts.dmg "https://github.com/Milomilo777/whisper-transcriber-suite/releases/download/v2.3.0/WhisperTranscriberSuite-v2.3.0-macOS-$A.dmg" && hdiutil attach -nobrowse -quiet -mountpoint /tmp/wts-dmg /tmp/wts.dmg && cp -R "/tmp/wts-dmg/Whisper Transcriber Suite.app" /Applications/ && hdiutil detach -quiet /tmp/wts-dmg && rm /tmp/wts.dmg && open "/Applications/Whisper Transcriber Suite.app"

Wolisz tradycyjny sposób? Otwórz .dmg i przeciągnij aplikację do folderu Programy; pierwsze uruchomienie wymaga kliknięcia prawym przyciskiem myszy → Otwórz (macOS 14 i starsze) lub przejścia do Ustawienia systemowe → Prywatność i ochrona → Otwórz mimo to (macOS 15+).

Nie chcesz jeszcze instalować? Najpierw wypróbuj krótki plik w przeglądarce. Wszystkie wydania wraz z opisami są na GitHub Releases. Instrukcja instalacji.

Czy Whisper Transcriber Suite jest darmowy?

Tak. Aplikacja jest na licencji BSD-3-Clause, bez subskrypcji i opłat za minutę. Sam model Whisper pobiera się raz (około 1-3 GB) przy pierwszym uruchomieniu; po tym transkrypcja działa bez połączenia z internetem.

Czy program przesyła gdziekolwiek moje pliki audio lub wideo?

Nie, domyślnie nie. Każdy domyślny backend — faster-whisper, whisper.cpp, NVIDIA Parakeet — działa lokalnie na Twoim komputerze. Dwa backendy wymagają ręcznego włączenia (chmurowy backend Gemini-API oraz Google Cloud Speech-to-Text) i oba pozostają wyłączone, dopóki nie włączysz ich samodzielnie w Ustawienia zaawansowane → Backend. Statystyki użycia (bez dźwięku i nazw plików) są domyślnie włączone i można je wyłączyć w Pomoc → Statystyki użycia, aplikacja sprawdza raz dziennie serwis GitHub pod kątem nowej wersji, a Plik → Praca offline całkowicie blokuje korzystanie z sieci.

Na jakich platformach działa program?

Windows, macOS i Linux. Udostępnione pliki do pobrania to instalator dla Windows, przenośny plik ZIP dla Windows oraz DMG dla macOS; na systemie Linux program uruchamia się ze źródeł.

Jakie formaty transkrypcji potrafi wygenerować?

srt vtt ass tsv txt json lrc md docx pdf oraz oTranscribe, ELAN, InqScribe i Express Scribe.

Czy program potrafi oznaczyć, kto mówi?

Tak — opcjonalna diaryzacja mówców („Identyfikuj mówców”), ze znacznikami czasu dla każdego słowa i przycinaniem zakresu czasu.

Czy program potrafi transkrybować na żywo dźwięk z mikrofonu lub systemu?

Tak, w zakładce Na żywo — mikrofon lub dźwięk systemowy, transkrybowany na bieżąco.

Czy program potrafi pobierać i transkrybować filmy online, np. z YouTube?

Tak, z dowolnej witryny obsługiwanej przez yt-dlp, z opcjonalną transkrypcją po zakończeniu pobierania.

Czy program potrafi podsumować transkrypcję, wyodrębnić zadania do wykonania lub odpowiedzieć na pytania na jej temat?

Tak, za pośrednictwem opcjonalnej zakładki Narzędzia AI w przeglądarce transkrypcji — podsumowanie, zadania do wykonania, zadawanie pytań oraz tłumaczenie poszczególnych segmentów generujące dwujęzyczny .srt. Funkcja jest domyślnie wyłączona.

Czy program potrafi sklonować głos i odczytać nim nowy tekst?

Tak, za pośrednictwem opcjonalnej zakładki Sklonuj swój głos, korzystającej z OmniVoice (Apache-2.0) w całości na Twoim komputerze. Domyślnie wyłączona; decydujesz o jej włączeniu podczas instalacji i musisz potwierdzić, że masz zgodę na klonowanie głosu referencyjnego.

Czym różni się to od bezpośredniego wywoływania API Whisper?

Domyślnie aplikacja uruchamia model lokalnie za pomocą faster-whisper, więc nie ma opłat za minutę API, a żadne dane audio nie opuszczają Twojego komputera — chyba że jawnie wybierzesz jeden z dwóch backendów chmurowych.

Czy kilka osób w tej samej sieci może korzystać z programu bez instalowania go na każdym komputerze?

Tak — tryb Dostęp przez sieć / LAN zamienia ten komputer w stronę do transkrypcji, z której mogą korzystać inne urządzenia w sieci.

What is new in version 2.3?

A globe button above the tabs switches the interface language, and Persian, Arabic and Hebrew now work on macOS too. On M-series Macs, Whisper runs on the GPU through Apple's MLX. Finished transcripts can be saved as Obsidian notes or sent to a webhook such as n8n, the built-in server guards the links it downloads and slows down wrong passwords, a download never overwrites a file with the same name, Live captions survive a crash, and Groq is one click away in Advanced → AI. More than 107 bugs were fixed. Version 2.2 brought Fast, Balanced or Best accuracy, models trained for one language, phone access by QR code, a right-to-left window on Windows and a page that transcribes a short file in your browser. Version 2.1 added the interface in 42 languages, reliable speaker labels and safer saving; version 2.0 added the queue's speed and time left, subtitled video from a link, transcripts as one offline web page, a checkable Work offline mode and translation to English. See What's new in 2.3 and the changelog.

Czy program potrafi przekształcić link do wideo w film z napisami?

Tak. W zakładce Pobierz wideo zaznacz Utwórz wideo z napisami: aplikacja pobiera wideo, wykonuje transkrypcję za pomocą Whisper i wtapia napisy przy użyciu ffmpeg, tworząc plik o nazwie wideo z -subbed.mp4. Pobrany plik oraz transkrypcja są zachowywane, a istniejący -subbed.mp4 nigdy nie zostanie nadpisany.

Czy mogę całkowicie odciąć aplikację od sieci?

Tak. Opcja Plik → Praca offline zatrzymuje sprawdzanie aktualizacji, statystyki użycia, pobieranie modeli i łączność ze zdalnymi dostawcami AI. Gdy jest włączona, wiersz na dole okna informuje, czy połączenie jest otwarte, a przycisk Sprawdź tryb offline teraz pokazuje, że połączenia testowe są odrzucane. Gdy jest wyłączona, aplikacja łączy się z siecią wyłącznie w celu sprawdzenia ustawień online przy uruchomieniu, codziennego sprawdzania aktualizacji, przesyłania statystyk użycia (które można wyłączyć w menu Pomoc → Statystyki użycia) oraz pobierania rozpoczętego przez Ciebie.
