홈 › YouTube 텍스트 변환

YouTube 동영상을 텍스트로 변환, 무료 및 오프라인

한 번 설치하면 자유롭게 쓸 수 있는 무료 데스크톱 앱입니다(Windows, macOS, Linux 지원). 동영상 다운로드에는 인터넷이 필요하지만, 전사 작업 자체는 사용자의 컴퓨터에서 실행됩니다.

YouTube 동영상을 텍스트로 변환하려면 '동영상 다운로드' 탭에 링크를 붙여넣고 텍스트 형식을 선택한 다음, '다운로드 후 전사'에 체크하고 '다운로드'를 클릭하세요. 앱이 오픈소스 다운로더인 yt-dlp로 동영상을 가져온 후, 사용자의 컴퓨터에서 음성 인식 모델인 Whisper로 전사하여 TXT, DOCX, PDF 또는 SRT 전사본으로 저장합니다.

No install? Try it in your browser: a free page that transcribes a short file (up to 10 minutes) on your device, with no upload and no sign-up. The app below handles longer files.

무료 앱 다운로드

시작하기 전에

설치 프로그램은 반드시 공식 GitHub 릴리스 페이지(홈페이지에서 연결됨)에서만 다운로드하세요. 코드 서명이 되어 있지 않아 Windows에서 처음 실행할 때 '추가 정보 > 실행' 경고가 표시될 수 있습니다. 시스템 요구 사항: 설치 가이드.

YouTube 동영상을 텍스트로 변환하는 방법

  1. 첫 실행 시에만 해당됩니다. '빠른 시작' 창에서 언어와 빠름 또는 최고 품질을 선택하도록 안내합니다. 음성 모델은 처음 사용할 때 한 번만 다운로드됩니다.
  2. Open the Download Videos tab and paste the YouTube link into Video link. The app looks up the formats and any subtitles by itself.
  3. 모드를 선택하세요. 오디오는 음성만 저장하므로 전사본만 필요한 경우 파일 용량이 작고 속도도 빠릅니다. 오디오 및 비디오를 선택하면 영상 화면도 함께 보관됩니다.
  4. Optional: open More options under the form and use Time range (optional) to download and transcribe only a part. The format is H:MM:SS, and 0:00:00 in both boxes means the whole video. More options opens by itself when a range is set.
  5. Choose the file type before you download. Switch to the Transcribe tab, click Advanced settings… and, under Output formats, tick TXT (or DOCX or PDF). The default is SRT plus JSON, which gives you subtitles, not a plain text file. Keep JSON ticked: it is a JSON file the app uses to open the transcript viewer. The Language and Accuracy level chosen on that tab apply to downloads too.
  6. '동영상 다운로드' 탭으로 돌아와 '다운로드 후 전사'에 체크한 다음 다운로드를 클릭하세요.
  7. 진행 상황을 확인하세요. 목록의 진행 상태가 채워지며, 전사 대기열 탭에 처리 속도와 남은 시간이 표시됩니다. 완료되면 전사본은 원본 파일과 같은 위치에 저장되고, '전사' 탭의 최근 결과 카드에서 열기, 전사본 보기, 공유용 페이지 저장 기능을 이용할 수 있습니다.

동영상에 이미 자막이 있는 경우 더 빠른 방법

검색된 동영상에 이미 자막이 있는 경우 링크 아래에 초록색으로 자막 사용 가능이라는 문구가 표시되며 대신 캡션 사용 버튼이 나타납니다. 이 기능은 미디어 다운로드와 전사를 건너뛰고 자막을 가져와 선택한 형식으로 변환합니다. 몇 분 대신 몇 초 만에 완료되지만, Whisper로 새로 전사하는 것이 아니라 기존 자막 그대로를 가져오게 됩니다. 다운로드 후 전사에 체크된 경우 앱에서 둘 중 어느 방식을 원하는지 묻고 선택을 기억할 수 있습니다.

로그인이 필요한 기타 사이트 및 동영상

Any site the same downloader supports works the same way. For videos that need an account, such as Instagram, Facebook, TikTok stories and age-restricted YouTube videos, open More options under the form and choose your browser under Log-in cookies. The app reads that browser's log-in on this computer and uses it only when downloading from that site; it is not sent anywhere else. This may not work for every restricted video.

알아두면 좋은 점

  • 인터넷 연결 없이는 다운로드할 수 없습니다. 파일 → 오프라인 작업이 켜져 있는 동안에는 앱이 링크 조회를 거부하므로, 링크를 붙여넣기 전에 이 설정을 꺼주세요.
  • YouTube를 이용하려면 간단한 도우미가 필요합니다. 링크 상태 옆에 YouTube 도우미 설치 버튼이 표시되면 한 번 클릭해 주세요. 도우미가 없으면 일부 또는 모든 YouTube 형식이 누락되거나 다운로드에 실패할 수 있습니다. 오래된 다운로더 버전으로 인해 다운로드가 실패하는 경우 업데이트 표시줄이 나타납니다.

질문

정말 무료인가요?

네, 계정이나 구독, 분당 요금이 없는 완전 무료 오픈소스입니다.

내 동영상이나 전사본이 외부로 업로드되나요?

기본 엔진을 사용할 때는 업로드되지 않습니다. Whisper는 사용자의 컴퓨터에서 직접 실행되며, 동영상 사이트에서 다운로드할 때만 네트워크를 사용합니다. 두 가지 클라우드 엔진도 지원하지만, 직접 켜기 전까지는 꺼져 있습니다.

자막이 없는 동영상이나 다른 언어로 된 동영상도 전사할 수 있나요?

네, 가능합니다. Whisper는 오디오를 직접 듣고 처리하므로 자막이 없어도 됩니다. 음성 언어를 선택하거나 자동으로 두세요. 출력: 영어 번역은 영어가 아닌 음성을 영어 텍스트로 변환해 줍니다. 기본적으로 꺼져 있으며 모든 엔진이나 모델에서 작동하는 것은 아닙니다.

긴 동영상의 일부분만 전사할 수도 있나요?

Yes. Open More options on the Download Videos tab and fill in Time range (optional) with a start and end in H:MM:SS. Only that portion is downloaded, and transcribed if you ticked Transcribe after download.

재생목록 전체를 붙여넣을 수도 있나요?

아니요, 작업마다 동영상 하나씩만 처리됩니다. 재생목록 내에서 복사한 링크는 전체 목록이 아닌 해당 동영상 하나만 다운로드합니다.
