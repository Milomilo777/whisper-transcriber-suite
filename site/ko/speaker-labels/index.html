홈 › 화자 라벨

화자 라벨(누가 어떤 말을 했는지)과 함께 인터뷰 전사하기

한 번 설치하면 되는 무료 데스크톱 앱입니다(Windows, macOS, Linux). 녹음 파일은 사용자의 컴퓨터에서 처리되며 계정이 필요하지 않습니다.

앱은 목소리를 구분해 '화자 00', '화자 01'처럼 라벨을 붙입니다. 이름을 붙여 주기 전에는 누구인지 알지 못합니다. 비슷한 목소리, 짧은 대답, 겹치는 발화, 배경 소음이 있으면 라벨이 틀릴 수 있습니다. 시작하려면 전사 탭에서 추가 옵션을 열고 화자 식별을 체크한 뒤 전사를 누르세요.

설치 없이 써 보고 싶으신가요? 브라우저에서 체험: 짧은 파일(최대 10분)을 내 기기에서 전사하는 무료 페이지로, 업로드도 가입도 필요 없습니다. 더 긴 파일은 아래의 앱으로 처리하세요.

무료 앱 다운로드

시작하기 전에

Windows 및 Mac 빌드에는 화자 감지 모델이 포함되어 있습니다. 설치 프로그램이 코드 서명되어 있지 않아 Windows에서 경고(추가 정보 > 실행)가 표시될 수 있으므로 앱은 반드시 공식 GitHub 릴리스 페이지에서만 다운로드하세요. 홈페이지와 설치 가이드도 함께 참조하세요.

전사본에 화자 라벨을 추가하는 방법

  1. 녹음 파일을 추가합니다. 전사 탭에서 오디오 또는 동영상 파일을 끌어다 놓거나 파일 찾아보기...를 클릭하세요. 동영상 다운로드 탭의 링크도 동일한 전사 설정을 사용하므로 마찬가지로 작동합니다.
  2. 언어를 선택하거나 자동으로 둡니다.
  3. 추가 옵션을 열고 화자 식별을 체크하세요. 체크박스에 화자 식별(사용 불가)이라고 표시되면 마우스를 올려 이유를 확인하세요. 그 아래의 화자 수 선택이 활성화됩니다. 자동으로 두거나, 2에서 10 사이의 숫자를 골라 정확히 그 인원으로 고정할 수 있습니다.
  4. 선택 사항: 추가 옵션에서 단어별 타임스탬프를 체크하면 문장마다가 아니라 모든 단어의 시작과 끝 시간이 저장됩니다. 출력 크기는 커집니다.
  5. 내보내기 형식을 선택합니다. 고급 설정…을 클릭하고 출력 형식에서 DOCX 및 PDF를 선택하세요. SRT, TXT, Markdown, JSON 형식에도 화자 라벨이 포함됩니다. JSON은 선택된 상태로 유지하세요. 마지막 단계에 필요한 전사 뷰어를 열 때 앱에서 이 JSON 파일을 사용합니다.
  6. 전사를 클릭하세요. 화자 감지는 전사가 끝난 후 실행되며 처리 시간이 추가됩니다. 완료되면 최근 결과 카드에서 전사본 보기를 여세요.
  7. 기본 라벨을 실제 이름으로 바꿉니다. 전사본 보기 창에서 화자 열의 셀을 마우스 오른쪽 버튼으로 클릭하고 'Speaker 00' 이름 바꾸기(모든 위치)...를 선택한 후 이름을 입력하고 변경 사항 저장(Ctrl+S)을 클릭하세요. 원본 전사본과 일치하는 경우 옆에 있는 Word 및 텍스트 파일이 다시 생성되지만, PDF는 다시 생성되지 않으므로 이름을 바꾼 후 다시 내보내야 합니다.

라벨이 표시되는 방식

각 세그먼트는 화자 이름으로 시작합니다. Word나 PDF 전사본에서는 각 줄에 타임스탬프, 굵은 글씨의 화자 이름, 텍스트 순으로 표시됩니다. SRT, VTT, TXT는 텍스트 앞에 Speaker 00:을 붙이고, ASS는 자체 이름 필드에 유지하며, JSON은 speaker 필드로 저장합니다. 공유 가능한 웹 페이지에서도 확인할 수 있습니다. 아래 줄은 레이아웃 예시이며 실제 출력물이 아닙니다:

[00:00:04]  Speaker 00:  So where do we start?
[00:00:07]  Speaker 01:  With the recording itself.

알아두면 좋은 점

  • 세그먼트당 하나의 라벨. 각 전사 세그먼트에는 감지된 발화가 가장 많이 겹치는 화자가 지정됩니다. 한 세그먼트 내에서 두 사람이 말하거나 말이 겹치는 경우에도 전체 세그먼트에 단 하나의 라벨만 지정됩니다. 겹치는 발화가 감지되지 않은 세그먼트에는 라벨이 지정되지 않습니다.
  • 개별 줄 수정하기. 이름을 바꾸면 해당 라벨이 지정된 모든 줄이 한꺼번에 변경됩니다. 전사본 보기 창에서는 특정 줄의 화자만 따로 변경할 수 없으므로, 개별 줄은 내보낸 Word 또는 텍스트 파일에서 직접 수정하세요.
  • 기본 이름. 라벨에는 번호가 매겨지며, 이 번호는 파일 하나 내에서는 일정하게 유지되지만 여러 파일 간에 연동되지는 않습니다.
  • 인원수가 맞지 않아 보이면 자동으로 두는 대신 화자 수를 실제 인원수로 설정하세요.
  • 오프라인 지원, Hugging Face 계정 불필요. 사용자 컴퓨터에서 직접 실행되며, 전사 외에 추가 처리 시간이 소요됩니다.
  • 단어 타이밍. 단어별 타임스탬프는 JSON 파일에 저장되며 VTT 및 ASS의 노래방 스타일 강조 표시에 사용됩니다.

질문

화자 이름을 자동으로 지정해 주나요?

기본적으로는 지원하지 않습니다. 라벨은 Speaker 00, Speaker 01 등으로 표시됩니다. 전사 뷰어의 이름 변경 옵션을 사용해 실제 이름으로 변경할 수 있습니다.

화자를 몇 명까지 구분할 수 있나요?

화자 수를 자동으로 두면 앱이 알아서 판단하며, 인원수를 알고 있다면 2에서 10 사이의 숫자를 직접 지정할 수도 있습니다.

동시에 말하는 사람들을 분리할 수 있나요?

아닙니다. 말이 겹치는 구간은 분리되지 않습니다. 한 구간에는 대부분을 차지한 화자의 라벨 하나만 지정됩니다. 이러한 구간은 직접 들어보고 확인하세요.

어떤 내보내기 형식에 화자 라벨이 표시되나요?

DOCX, PDF, SRT, VTT, TXT, Markdown, ASS, JSON 및 공유 가능한 웹 페이지입니다.
