파일을 끌어다 놓고 옵션을 선택한 뒤 '전사'를 누르세요. 그 밖의 모든 기능은 — 대기열, 다운로드, 실시간 캡처, 목소리 복제, LAN 공유 — 탭 하나만 넘기면 바로 이용할 수 있습니다. 링을 드래그하거나 화살표를 사용해 보세요.

전사

파일 드롭 영역, 엔진, 모델 및 언어 선택기, 화자 라벨 및 단어별 타임스탬프 옵션.

2.1의 새로운 기능

2.1의 새로운 기능. 이제 여러분의 언어로 만나보세요.

42개 언어로 지원되는 앱, 긴 녹음의 끝까지 유지되는 화자 라벨, 정전에도 안전한 파일, 그리고 모든 Mac에서 정상 작동하는 온라인 기능. 그 아래에는 2.0에서 추가된 기능이 이어집니다.

2.1 · 모든 플랫폼

여러분의 언어로 만나는 앱

메뉴, 버튼, 메시지가 42개 언어로 제공됩니다(macOS 및 Linux에서는 39개 언어). 앱은 시스템 언어를 따르며, 고급 설정에서 직접 선택할 수도 있습니다. 영어를 제외한 모든 언어는 기계 번역이며 그에 맞게 표시됩니다. 페르시아어, 아랍어, 히브리어는 현재 Windows에서만 제공됩니다.

2.1 · 모든 플랫폼

믿을 수 있는 화자 라벨

이제 긴 녹음 파일에서도 화자 이름이 끝까지 유지되며, 화자 감지 때문에 전사가 중단되는 일도 없습니다. 또한 화자 식별 옆에서 '자동' 대신 대화자 수(2~10명)를 직접 설정할 수 있습니다.

2.1 · 모든 플랫폼

더욱 안전해진 작업

전사본, 내보내기 파일 및 자막은 기존 파일을 대체하기 전에 디스크에 완전히 기록되므로, 정전이 발생하더라도 파일이 빈 채로 남을 염려가 없습니다. 모든 파일을 저장한 뒤 워커가 중단된 전사 작업 역시 완료된 것으로 정상 처리됩니다.

2.1 · macOS

모든 Mac에서 지원되는 온라인 기능

업데이트 확인, 문제 보고 및 기타 웹 조회 작업이 더 이상 certificate verify failed 오류로 실패하지 않습니다.

2.0 · 모든 플랫폼

속도 및 남은 시간

전사 대기열 탭에서는 각 전사 작업의 처리 속도와 대략적인 남은 시간을 보여줍니다(예: 약 4.8배속, 6분 남음). 작업이 끝나면 결과 카드에 속도, 사용된 모델 및 기기 정보가 표시됩니다.

2.0 · 모든 플랫폼

자막 동영상 만들기

동영상 다운로드 탭에서 이 옵션을 선택하면 링크가 자막이 입혀진 <title>-subbed.mp4 파일로 완성됩니다. 다운로드, 전사, 자막 합성이 하나의 대기열 작업으로 진행되며 실시간 진행률 확인과 정상 작동하는 '취소' 기능을 지원합니다. 다운로드 원본과 전사본도 함께 보관됩니다.

2.0 · 모든 플랫폼

전사본을 단일 웹 페이지로 공유

완료된 전사본을 별도의 설치나 인터넷 연결 없이 모든 브라우저에서 열 수 있는 단일 .html 파일로 저장해 보세요. 타임스탬프, 화자, 챕터 및 검색창이 제공되며, 단어를 클릭하면 해당 위치부터 미디어가 재생됩니다.

2.0 · 모든 플랫폼

눈으로 확인하는 오프라인 작업

'파일' 메뉴의 스위치 하나로 앱의 네트워크 연결을 완전히 차단할 수 있습니다. 창 하단의 상태 표시줄에서 연결이 열려 있는지 확인할 수 있으며, 지금 오프라인 확인을 누르면 테스트 연결이 거부되는 과정을 직접 보여줍니다. 사용 통계는 기본적으로 켜져 있으며 '도움말'에서 끌 수 있습니다.

2.0 · 모든 플랫폼

음성을 영어로 번역

출력: 영어 번역 옵션은 Whisper의 자체 번역 작업을 활용하여 영어가 아닌 음성을 한 번에 영어 자막으로 변환합니다. 기본적으로 꺼져 있으며, 모든 엔진이나 모델에서 지원되는 것은 아닙니다.

2.0 · macOS

Mac다운 자연스러운 경험

설정(Command-comma)이 포함된 앱 메뉴, macOS 설정을 따르는 라이트 및 다크 모드, 시스템 글꼴, Finder에서 열거나 Dock 아이콘으로 드롭한 파일 지원, 앱이 백그라운드에 있을 때 작업이 완료되면 표시되는 알림을 제공합니다.

2.0 · Windows

작업 표시줄 진행 상태와 어두운 제목 표시줄

작업 표시줄 버튼에 진행 상태와 대기 및 실행 중인 작업 수가 표시되며, 작업이 끝나면 버튼이 깜빡입니다. 제목 표시줄은 다크 테마를 따르며, 125% 및 150% 디스플레이 배율에서도 텍스트가 선명하게 유지됩니다.

2.0 · 첫 실행

빠른 시작과 샘플 클립

새로 설치하면 언어, 빠름 또는 최고 품질, 폴더를 선택하도록 안내하며, 다운로드가 시작되기 전에 모델 크기를 미리 보여줍니다. 18초 분량의 퍼블릭 도메인 클립을 제공하므로 직접 파일을 선택하기 전에 실제 전사 결과를 먼저 확인해 볼 수 있습니다.

2.0의 또 다른 변경 사항: Text to Voice가 최대 100,000자의 텍스트를 나누어 읽어주며, 업데이트 버튼으로 관리자 권한 없이 동영상 다운로더를 업데이트할 수 있고, 업데이트 대화 상자 대신 방해되지 않는 업데이트 표시줄이 도입되었습니다. Video Tiling 탭은 제거되었습니다. 모든 세부 사항은 변경 로그에서 확인하실 수 있습니다.

작동 방식

사용자의 컴퓨터에서 직접 실행됩니다. 오디오 파일은 외부로 유출되지 않습니다.

전사는 사용자의 컴퓨터에서 직접 실행됩니다. 선택 기능인 두 가지 클라우드 엔진 중 하나를 켰을 때만 오디오가 업로드되며, 전사 텍스트 역시 원격 AI 모델을 직접 연결한 경우에만 외부로 전송됩니다.

  1. 01

    파일을 드롭하거나 링크 붙여넣기

    디스크의 오디오나 동영상은 물론 yt-dlp가 가져올 수 있는 모든 미디어를 지원합니다. Tk 인터페이스가 메인 프로세스에서 실행되어 작업을 대기열에 즉시 등록합니다.

  2. 02

    워커 프로세스가 모델을 메모리에 유지

    모든 작업은 Whisper를 메모리에 유지하는 독립된 상주형 워커 서브프로세스에서 실행되며, 줄바꿈으로 구분된 JSON을 통해 진행 상황을 스트리밍하므로 창이 절대 멈추지 않습니다.

  3. 03

    원본 파일 옆에 바로 저장되는 전사 결과

    워커별 토큰과 하트비트 덕분에 라우팅이 견고하게 유지되며, 워커가 멈추더라도 앱이 함께 멈추는 대신 중단된 워커를 바로 감지합니다.

OpenAI의 Whisper 음성 인식 모델을 기반으로 구축되었으며, faster-whisper, whisper.cpp, NVIDIA Parakeet를 통해 로컬에서 실행되고, 미디어 처리를 위해 yt-dlp 및 FFmpeg을 활용합니다.

macOS — 한 줄 설치

터미널에 붙여넣기만 하면 끝입니다.

사용자의 Mac에 맞는 빌드(macOS 14 이상에서는 Apple Silicon, 그 외에는 Rosetta를 통한 Intel)를 다운로드하여 앱을 Applications에 복사하고 실행합니다. curl에서 가져온 파일은 격리되지 않으므로, "확인되지 않은 개발자" 경고를 클릭해 넘길 필요가 없습니다.

A=x64; [ "$(uname -m)" = arm64 ] && [ "$(sw_vers -productVersion | cut -d. -f1)" -ge 14 ] && A=arm64; curl -fL -o /tmp/wts.dmg "https://github.com/Milomilo777/whisper-transcriber-suite/releases/download/v2.1.0/WhisperTranscriberSuite-v2.1.0-macOS-$A.dmg" && hdiutil attach -nobrowse -quiet -mountpoint /tmp/wts-dmg /tmp/wts.dmg && cp -R "/tmp/wts-dmg/Whisper Transcriber Suite.app" /Applications/ && hdiutil detach -quiet /tmp/wts-dmg && rm /tmp/wts.dmg && open "/Applications/Whisper Transcriber Suite.app"

기존 방식을 선호하시나요? .dmg을 열고 앱을 Applications 폴더로 드래그하세요. 처음 실행할 때는 마우스 우클릭 → 열기(macOS 14 및 이전 버전)를 선택하거나 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기(macOS 15 이상)를 선택해야 합니다.

릴리스 노트를 포함한 모든 버전은 GitHub Releases에서 확인할 수 있습니다. 설치 가이드.

FAQ

자주 묻는 질문

다른 궁금한 점이 있으신가요? GitHub Discussions에 질문해 보세요.

Whisper Transcriber Suite는 무료인가요?

네, 무료입니다. BSD-3-Clause 라이선스가 적용되어 구독료나 분당 사용료가 전혀 없습니다. Whisper 모델 자체는 최초 실행 시 한 번만 다운로드(약 1-3 GB)되며, 이후에는 인터넷 연결 없이도 전사 기능이 작동합니다.

오디오나 비디오가 외부로 업로드되나요?

기본적으로는 전송되지 않습니다. faster-whisper, whisper.cpp, NVIDIA Parakeet 등 모든 기본 백엔드는 사용자의 컴퓨터에서 로컬로 실행됩니다. 두 가지 백엔드(클라우드 Gemini API 백엔드 및 Google Cloud Speech-to-Text)는 사용자가 직접 선택할 때만 동작하며, 고급 → 백엔드에서 활성화하기 전까지는 꺼져 있습니다. 사용 통계(오디오나 파일 이름 제외)는 기본적으로 켜져 있으며 도움말 → 사용 통계에서 끌 수 있습니다. 앱은 매일 한 번 GitHub에서 새 버전을 확인하며, 파일 → 오프라인 작업을 설정하면 모든 네트워크 사용이 중지됩니다.

어떤 플랫폼에서 실행할 수 있나요?

Windows, macOS 및 Linux를 지원합니다. 배포되는 다운로드 파일은 Windows 설치 프로그램, Windows 포터블 ZIP, macOS DMG 파일이며, Linux는 소스 코드에서 실행할 수 있습니다.

어떤 전사 형식을 생성할 수 있나요?

srt vtt ass tsv txt json lrc md docx pdf 외에도 oTranscribe, ELAN, InqScribe 및 Express Scribe를 지원합니다.

누가 말하고 있는지 화자를 구분하여 표시할 수 있나요?

네 — 선택 가능한 화자 분리("화자 식별") 기능을 제공하며, 단어별 타임스탬프 및 시간 구간 클리핑을 지원합니다.

마이크나 시스템 오디오를 실시간으로 전사할 수 있나요?

네, 실시간 탭에서 마이크나 시스템 오디오를 실시간으로 전사할 수 있습니다.

YouTube 등 온라인 동영상을 다운로드하여 전사할 수 있나요?

네, yt-dlp가 지원하는 모든 사이트에서 가능하며, 다운로드 완료 후 자동 전사 옵션도 제공합니다.

전사본을 요약하거나 작업 항목을 추출하고, 내용에 대한 질문에 답변할 수 있나요?

네, 전사본 뷰어의 선택 기능인 AI 도구 탭에서 요약, 액션 아이템 생성, 질문하기, 이중 언어 .srt을 생성하는 세그먼트별 번역 기능을 이용할 수 있습니다. 기본적으로는 꺼져 있습니다.

목소리를 복제하여 새로운 텍스트를 말하게 할 수 있나요?

네, 선택 기능인 목소리 복제(Clone Your Voice) 탭에서 사용자의 컴퓨터에서 완전히 동작하는 OmniVoice (Apache-2.0)를 통해 지원합니다. 기본적으로는 꺼져 있으며 설치 시 활성화할 수 있습니다. 사용 시에는 참조 목소리를 복제할 권한이 있음을 확인해야 합니다.

Whisper API를 직접 호출하는 것과 어떻게 다른가요?

기본적으로 faster-whisper를 통해 모델을 로컬에서 실행하므로 분당 API 비용이 발생하지 않으며, 사용자가 두 가지 클라우드 백엔드 중 하나를 직접 선택하지 않는 한 오디오가 사용자의 기기 외부로 전송되지 않습니다.

모든 기기에 설치하지 않고도 같은 네트워크에 있는 여러 사람이 함께 사용할 수 있나요?

네 — 웹/LAN 접속 모드를 통해 이 컴퓨터를 네트워크의 다른 기기에서도 사용할 수 있는 전사 페이지로 전환할 수 있습니다.

버전 2.1에서는 무엇이 새로워졌나요?

메뉴, 버튼, 메시지는 42개 언어로 제공됩니다(기계 번역으로 표시됨). 긴 녹음에서도 화자 라벨이 끝까지 유지되며 대화 참여자 수를 설정할 수 있습니다. 전사본, 내보내기 파일, 자막은 기존 파일을 교체하기 전에 디스크에 완전히 기록되며, 모든 Mac에서 온라인 기능이 동작합니다. 버전 2.0에서는 대기열의 속도와 남은 시간 표시, 링크 기반 자막 동영상 제작, 단일 오프라인 웹페이지 형태의 전사본, 체크 가능한 오프라인 작업 모드, 영어 번역 기능이 추가되었습니다. 2.1 새로운 기능과 변경 로그를 확인해 보세요.

동영상 링크를 자막이 포함된 동영상으로 만들 수 있나요?

네. 동영상 다운로드 탭에서 자막 동영상 만들기를 선택하세요. 앱이 동영상을 다운로드하여 Whisper로 전사하고 ffmpeg로 자막을 입혀, 동영상 이름 뒤에 -subbed.mp4가 붙은 파일을 만듭니다. 다운로드한 파일과 전사본은 유지되며, 기존 -subbed.mp4 파일은 절대 덮어쓰지 않습니다.

앱의 네트워크 연결을 완전히 차단한 상태로 사용할 수 있나요?

네. 파일 → 오프라인 작업을 사용하면 업데이트 확인, 사용 통계, 모델 다운로드 및 원격 AI 제공자 연결이 중지됩니다. 이 모드가 켜져 있는 동안에는 창 하단의 문구를 통해 연결이 열려 있는지 표시되며, 지금 오프라인 확인을 누르면 테스트 연결이 거부되는 것을 확인할 수 있습니다. 이 모드를 끄면 앱은 시작 시 온라인 설정, 매일 진행되는 업데이트 확인, 사용 통계(도움말 → 사용 통계에서 끌 수 있음), 사용자가 직접 시작한 다운로드 시에만 네트워크에 연결합니다.
