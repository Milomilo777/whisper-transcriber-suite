동영상을 무료로 SRT 자막으로 변환하는 방법

한 번 설치하여 사용하는 무료 데스크톱 앱입니다(Windows, macOS, Linux). 앱에 내장된 음성 인식 모델인 Whisper가 컴퓨터에서 직접 실행되므로, 기본 엔진을 사용하면 동영상이 업로드되지 않습니다.

동영상을 SRT 자막으로 변환하려면 전사 탭을 열고 동영상이나 오디오 파일을 끌어다 놓은 뒤, 고급 설정에서 SRT가 선택되어 있는지 확인하고 전사를 누르세요. Whisper가 원본 파일 옆에 범용 자막 형식인 SRT 파일을 생성하므로 동영상 플레이어, 편집기 또는 업로드에 바로 활용할 수 있습니다. 링크를 사용하려면 YouTube 가이드를 참조하세요.

설치 없이 써 보고 싶으신가요? 브라우저에서 체험: 짧은 파일(최대 10분)을 내 기기에서 전사하는 무료 페이지로, 업로드도 가입도 필요 없습니다. 더 긴 파일은 아래의 앱으로 처리하세요.

무료 앱 다운로드

시작하기 전에

다운로드는 홈페이지에서 제공되며 요구 사양은 설치 가이드에서 확인할 수 있습니다. 설치 프로그램은 코드 서명이 되어 있지 않아 Windows에서 처음 실행할 때 경고가 표시될 수 있으므로(추가 정보 > 실행), 반드시 공식 GitHub 릴리스 페이지만 이용하세요.

1. SRT 만들기

  1. 전사 탭을 열고 동영상 또는 오디오 파일을 창으로 끌어다 놓거나 파일 찾아보기...를 클릭하세요. 여러 파일을 한 번에 선택할 수도 있습니다.
  2. 언어를 설정하거나 자동으로 두어 감지하게 하세요. 짧거나 잡음이 많은 클립은 직접 고르는 편이 더 빠르고 정확할 수 있습니다. 그 옆의 정확도가 모델을 정합니다. 빠름은 빠른 초안용, 균형, 최고는 가장 꼼꼼한 결과(느림)입니다. 고급 설정에서 직접 고른 모델은 사용자 지정으로 표시되며 그대로 유지됩니다.
  3. 선택 사항: 추가 옵션을 열고 시간 범위(H:MM:SS)를 입력하면 파일의 일부만 전사합니다.
  4. 자막 형식을 선택합니다. 고급 설정…을 클릭하고 출력 형식을 찾으세요. 기본값은 SRT와 JSON입니다. 웹 동영상용으로는 VTT(웹 자막 형식)를 선택하고, 편집기에서 자막 스타일을 적용할 경우 ASS (스타일 자막 / 노래방)를 선택하세요. 선택한 모든 형식의 파일이 작업마다 생성됩니다. JSON은 선택된 상태로 유지하세요. 앱에서 전사본 보기를 열 때 이 JSON 파일이 필요합니다.
  5. 선택 사항: 추가 옵션에서 단어별 타임스탬프를 체크하면 모든 단어의 시작과 끝 시간이 저장됩니다. 파일 크기는 커집니다. SRT 자막은 여전히 발화 한 구간당 하나의 큐로 나뉩니다. 단어 타이밍은 VTT와 ASS에서 노래방 스타일 강조에 쓰입니다.
  6. 전사를 클릭합니다. 작업 진행 상황은 전사 대기열 탭에서 확인할 수 있습니다. 자막 파일은 원본 파일과 같은 위치에 동일한 이름과 새 확장자로 저장됩니다(예: talk.mp4는 talk.srt로 저장됨). 최근 결과 카드에는 각 파일의 열기 버튼이 표시됩니다.

다른 언어 자막

영어가 아닌 음성에 영어 자막을 만들려면 추가 옵션을 열고 출력: 영어 번역을 체크하세요. 파일 이름에 .en-translated가 붙습니다. 기본값은 꺼짐이며, 모든 엔진이나 모델에서 되는 것은 아닙니다. 다른 언어는 전사본 뷰어의 선택형 AI 도구 탭에서 AI 계층(직접 설치하는 로컬 모델 또는 직접 고르는 온라인 서비스)을 설정하면 이중 언어 SRT를 만들 수 있으며, 이 기능도 기본값은 꺼짐입니다.

2. 수정하기(선택 사항)

최근 결과 카드에서 전사본 보기를 엽니다(기본적으로 선택되어 있는 JSON 출력이 필요합니다). 찾기 및 바꾸기와 군말 제거로 텍스트를 수정할 수 있으며, 줄 단위 편집은 원하는 자막 편집기를 사용하세요. 세그먼트를 마우스 오른쪽 버튼으로 클릭하고 타임스탬프 편집...을 선택하면 해당 세그먼트의 시작과 끝 시간을 변경할 수 있으며 다른 세그먼트는 이동하지 않습니다.

변경 사항 저장(Ctrl+S)을 클릭합니다. 앱이 전사본을 저장한 후, 수정된 전사본을 바탕으로 옆에 있는 .srt 및 기타 텍스트 파일을 다시 생성하여 덮어씁니다. 다른 곳에서 수정한 파일은 건드리지 않으며, 해당 파일에 이전 텍스트가 여전히 유지되어 있음을 앱이 알려줍니다. PDF는 다시 생성되지 않습니다. Windows에서는 Subtitle Edit에서 열기를 통해 타이밍을 미세 조정할 수 있는 파형 뷰를 지원하는 무료 편집기에서 자막 파일을 열 수 있습니다.

3. 동영상에 자막 입히기(선택 사항)

링크를 사용하는 경우: 모드를 오디오 및 비디오로 유지하고 자막 동영상 만들기를 선택한 후 다운로드를 클릭하세요. 앱이 다운로드와 전사를 거쳐 동영상 이름 끝에 -subbed.mp4가 붙은 새 파일에 자막을 입혀 생성합니다. 다운로드한 파일과 전사본은 그대로 보존되며, 기존의 -subbed.mp4 파일은 덮어쓰지 않습니다.

이미 전사한 파일의 경우: 전사 대기열 탭을 열고 완료된 항목을 마우스 오른쪽 버튼으로 클릭한 뒤 동영상에 자막 입히기...를 선택하세요. SRT 파일이 필요하므로 출력 형식에서 SRT를 선택된 상태로 유지해야 합니다. 결과물은 스마트폰, TV, 브라우저에서 재생 가능한 MP4 파일로 생성됩니다. 다시 인코딩하는 데 다소 시간이 걸리며, 소요 시간은 컴퓨터 성능에 따라 달라집니다.

알아두면 좋은 점

  • 타이밍. SRT 시간은 Whisper의 세그먼트를 따릅니다. 고급 설정의 stable-ts로 단어 타이밍 미세 조정(더 느림)은 단어 타이밍의 정확도를 높여주는 선택형 추가 단계이며, 처음 실행할 때 관련 구성 요소를 다운로드합니다.
  • 게시 전 확인하세요. 앱이 반복되거나 지어낸 문장을 표시해 주지만, 인명이나 숫자는 직접 한 번 더 확인하는 것이 좋습니다.

질문

어떤 자막 형식을 지원하나요?

SRT, VTT, ASS뿐만 아니라 TSV, TXT, JSON, LRC, Markdown, DOCX, PDF 및 oTranscribe, ELAN, InqScribe, Express Scribe 형식을 지원합니다.

YouTube나 동영상 편집기에 SRT를 어떻게 추가하나요?

.srt 파일을 자막 파일로 업로드하거나 가져오세요. 앱이 동영상과 같은 위치에 동일한 이름의 .srt 확장자로 자막을 저장합니다.

동영상이 외부로 업로드되나요?

아니요, 기본 엔진을 사용할 때는 업로드되지 않습니다. 두 가지 클라우드 엔진이 있지만 직접 켜기 전까지는 꺼져 있으며, 파일 → 오프라인 작업을 선택하면 모든 네트워크 사용이 차단됩니다.
