轉錄訪談並加上說話者標籤（誰說了什麼）

一次安裝即可使用的免費桌面軟體（Windows、macOS、Linux）。錄音檔案全程在您的電腦上處理，無需註冊帳號。

軟體能辨別不同聲音，並依序標記為 Speaker 00、Speaker 01 等。在您重新命名之前，它無法得知說話者的真實身分。聲音相近、簡短回答、多人重疊發話或背景雜音都可能導致標籤有誤。開始時，請在「轉錄」分頁勾選「辨識說話者」，然後按下「轉錄」。

下載免費軟體

開始之前

Windows 與 Mac 版本已內建說話者偵測模型。請務必僅從 GitHub 官方發布頁面 下載軟體；安裝程式未經程式碼簽署，因此 Windows 可能會顯示警告（其他資訊 > 仍要執行）。另請參閱 首頁 與 安裝指南。

如何在逐字稿中新增說話者標籤

  1. 新增錄音檔案。在 轉錄 分頁中，將音訊或影片檔案拖曳進來，或點選 瀏覽檔案…。使用 下載影片 分頁的連結也可以，因為兩者使用相同的轉錄設定。
  2. 選擇語言，或保留為 自動。
  3. 勾選辨識說話者。若該方塊顯示為 辨識說話者（無法使用），請將滑鼠游標懸停在上方查看原因。其下方的 說話者人數 選取器將會啟用：可保留為 自動，或手動指定 2 到 10 人以強制設定確切的人數。
  4. 選用：勾選 逐字時間戳記 可儲存每個單字的開始與結束時間，而非僅有每個句子。輸出的檔案會隨之變大。
  5. 選取匯出格式。點選 進階設定… 並在 輸出格式 下勾選 DOCX 與 PDF。SRT、TXT、Markdown 與 JSON 同樣會包含說話者標籤。請保持勾選 JSON：軟體需要使用此 JSON 檔案開啟逐字稿檢視器，最後一步將會用到它。
  6. 按一下「轉錄」。說話者偵測會在語音轉錄完成後執行，因此需要額外的處理時間。完成後，從 最新結果 卡片中開啟 檢視逐字稿。
  7. 將預設標籤替換為姓名。在檢視器中，於 說話者 欄位的儲存格按右鍵，選擇 重新命名「Speaker 00」（所有位置）…，輸入姓名後按一下 儲存變更 (Ctrl+S)。若旁邊的 Word 與文字檔案仍與原始逐字稿內容相符，則會自動重新產生；PDF 檔案不會自動更新，因此在重新命名後請再次手動匯出。

標籤外觀範例

每個片段開頭都會標註說話者。在 Word 或 PDF 逐字稿中，每行依序顯示時間戳記、以粗體標示的說話者，隨後為文字內容。SRT、VTT 與 TXT 會在文字前加上 Speaker 00:，ASS 會將其保留在專屬的名稱欄位，而 JSON 則會以 speaker 欄位儲存。可分享的網頁版同樣會顯示此標籤。以下文字僅為排版呈現範例，並非實際轉錄內容：

[00:00:04]  Speaker 00:  So where do we start?
[00:00:07]  Speaker 01:  With the recording itself.

實用須知

  • 每個片段一個標籤。逐字稿中的每個片段都會標註語音重疊時間最長的說話者。若兩人在同一片段內說話或互相重疊發話，整個片段仍只會帶有單一標籤。若片段完全未與偵測到的語音重疊，則不會標註任何標籤。
  • 修改單一行。重新命名功能會一次變更所有帶有該標籤的行。檢視器無法單獨修改某一行的說話者，因此若需修正單一行，請在匯出的 Word 或文字檔案中手動編輯。
  • 通用名稱。標籤以編號命名，同一檔案內的編號保持一致，但跨檔案之間則不具對應關係。
  • 若偵測人數有誤，請將 說話者人數 設為實際人數，不要保留為「自動」。
  • 完全離線，無需 Hugging Face 帳號。模型完全在您自己的電腦上執行，會在語音轉錄之餘增加額外的處理時間。
  • 逐字時間戳記。逐字時間戳記會儲存在 JSON 檔案中，供 VTT 與 ASS 用於卡拉 OK 般的反白效果。

常見問題

它會幫我命名說話者嗎？

無法直接做到。標籤會顯示為 Speaker 00、Speaker 01 等。請使用逐字稿檢視器中的重新命名選項，將它們改為姓名。

它能區分幾位說話者？

將 說話者 維持在 自動，由軟體自行決定；若您知道人數，也可以強制指定 2 到 10 之間的數字。

它能分開同時說話的人嗎？

不行。重疊對話不會被拆分：每個片段只會獲得一個標籤，也就是涵蓋大部分時間的講者。請透過試聽來檢查這些段落。

哪些匯出格式會顯示說話者標籤？

DOCX、PDF、SRT、VTT、TXT、Markdown、ASS、JSON 以及可分享的網頁。
