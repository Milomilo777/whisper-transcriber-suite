如何免費將影片轉換為 SRT 字幕

一次安裝即可使用的免費桌面軟體（Windows、macOS、Linux）。其內建的 Whisper 語音辨識模型會在您的電腦上執行，因此使用預設引擎時，影片不會被上傳。

若要將影片轉換為 SRT 字幕，請開啟「轉錄」分頁，將影片或音訊檔案拖放進來，確認「進階設定」中的 SRT 已勾選，然後按下「轉錄」。Whisper 會在原始檔案旁產生通用的 SRT 字幕檔案，方便直接用於播放器、剪輯軟體或上傳。若要透過連結轉換，請參閱 YouTube 指南。

不想安裝嗎？在瀏覽器中試用：一個免費頁面，直接在你的裝置上轉錄短檔案（最長 10 分鐘），不上傳、免註冊。較長的檔案請用下方的應用程式。

下載免費軟體

開始之前

下載連結位於 首頁；系統需求請見 安裝指南。請務必僅透過 GitHub 官方發布頁面 下載：由於安裝程式未經程式碼簽署，Windows 在首次啟動時可能會顯示警告（其他資訊 > 仍要執行）。

1. 製作 SRT

  1. 開啟「轉錄」分頁，並將影片或音訊檔案拖曳至視窗中，或點擊 瀏覽檔案…。您可以一次選取多個檔案。
  2. 設定語言，或保持自動讓應用程式偵測。對於較短或雜音較多的片段，自己指定更快，也可能更準確。旁邊的準確度決定使用的模型：快速適合快速出草稿，平衡，最佳結果最細緻（較慢）。你在進階設定裡選定的模型會顯示為自訂，不會被更動。
  3. 選填：展開更多選項，填入時間範圍（H:MM:SS），只轉錄檔案的一部分。
  4. 選擇字幕格式。點選 進階設定… 並找到 輸出格式。預設格式為 SRT 與 JSON。網路影片可勾選 VTT（網頁字幕格式），若要在編輯器中自訂字幕樣式則可勾選 ASS（樣式字幕／卡拉 OK）。每個任務都會輸出所有已勾選的格式。請保持勾選 JSON：軟體需要透過此 JSON 檔案開啟逐字稿檢視器。
  5. 選填：在更多選項裡勾選逐字時間戳記，為每個字儲存開始和結束時間；檔案會變大。SRT 字幕仍依整段語音分割，每段一則。字詞時間用於 VTT 和 ASS 的卡拉 OK 式醒目提示。
  6. 點擊轉錄。您可以在 轉錄佇列 分頁追蹤任務進度。字幕檔案會以相同檔名與新的副檔名儲存在原始檔案旁（例如 talk.mp4 會產生 talk.srt），而 最新結果 卡片也會為每個檔案提供 開啟 按鈕。

其他語言的字幕

要為非英語語音產生英文字幕，請展開更多選項並勾選輸出：英文翻譯；檔名會帶有 .en-translated。預設關閉，也並非所有引擎或模型都支援。其他語言可使用逐字稿檢視器中選用的 AI 工具分頁，在設定好 AI 層（你自行安裝的本機模型，或你選擇的線上服務）後產生雙語 SRT；它預設也是關閉的。

2. 校對字幕（選用）

從 最新結果 卡片開啟 檢視逐字稿（此功能需要 JSON 輸出格式，預設已勾選）。尋找與取代 及 移除贅字 可修改文字；若需逐行編輯，可搭配任何字幕編輯軟體。在片段上按右鍵並選擇 編輯時間戳記… 即可調整該片段的起訖時間，其他片段則不受影響。

點選 儲存變更 (Ctrl+S)：軟體會儲存逐字稿，並根據編輯後的逐字稿重新產生並取代旁邊的 .srt 與其他文字檔案。若您在其他地方修改過該檔案，軟體將保持該檔案不變，並提示其仍保留舊文字。PDF 檔案絕不會重新產生。在 Windows 上，點選 在 Subtitle Edit 中開啟 可在該免費編輯器中開啟字幕，利用其波形圖檢視微調時間軸。

3. 內嵌字幕（選用）

透過連結：將模式保持為 音訊與影片，勾選 製作含字幕影片 並點擊 下載。軟體會自動下載、轉錄並將字幕內嵌至新檔案中，新檔名會以影片名稱加上 -subbed.mp4 結尾。原始下載檔與逐字稿均會保留，且絕不會覆蓋已存在的 -subbed.mp4 檔案。

從已轉錄的檔案：開啟 轉錄佇列 分頁，在已完成的項目上按右鍵並選擇 將字幕燒錄至影片…。此操作需要 SRT 檔案，因此請在「輸出格式」中保持勾選 SRT。產出結果為相容手機、電視與瀏覽器播放的 MP4 影片。重新編碼需要花費一些時間，具體時間取決於您的電腦效能。

實用須知

  • 時間軸。SRT 時間點是以 Whisper 的語音區段為基準。「進階設定」中的 使用 stable-ts 微調逐字時間戳記（較慢） 是選用的額外步驟，能讓逐字時間戳記更為精準；首次啟用時會下載額外元件。
  • 發布前請先檢查。軟體會標記重複或憑空捏造的內容，但人名與數字仍值得您親自核對一次。

常見問題

它支援輸出哪些字幕格式？

SRT、VTT 與 ASS，以及 TSV、TXT、JSON、LRC、Markdown、DOCX 與 PDF，並支援 oTranscribe、ELAN、InqScribe 及 Express Scribe 格式。

如何將 SRT 新增至 YouTube 或影片剪輯軟體？

將 .srt 作為字幕檔案上傳或匯入即可。軟體會將其儲存在影片旁，具有相同的檔名並以 .srt 作為副檔名。

我的影片會被上傳嗎？

不會，使用預設引擎時絕不上傳。雖然提供兩種雲端引擎，但在您自行開啟之前都會保持關閉，且點選 檔案 → 離線工作 即可停止所有網路連線。
