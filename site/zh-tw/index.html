運作方式

完全在您的電腦上運作。您的音訊始終留在本機。

轉錄作業完全在您自己的電腦上執行。只有在您開啟兩種選用的雲端引擎之一時，音訊才會上傳；而逐字稿文字也只有在您自行連接遠端 AI 模型時才會離開本機。

  1. 01

    拖放檔案，或貼上連結

    本機磁碟中的音訊或影片，或是任何 yt-dlp 能抓取的內容。Tk 介面在主行程中執行，能立即將工作排入佇列。

  2. 02

    由工作程序常駐模型

    每項工作都在專屬的長效 worker 子行程中執行，將 Whisper 常駐於記憶體中，並透過以換行字元分隔的 JSON 串流即時回傳進度 —— 確保視窗永遠不會停止回應。

  3. 03

    逐字稿直接產生在您的檔案旁

    透過各工作行程專屬的權杖與心跳訊號保持通訊穩定，並讓應用程式能主動偵測停滯的工作行程，避免跟著卡死。

以 OpenAI 的 Whisper 語音辨識模型 為核心建構，透過 faster-whisper、whisper.cpp 或 NVIDIA Parakeet 於本機端執行，並採用 yt-dlp 與 FFmpeg 進行媒體處理。

Whisper Transcriber Suite 是免費的嗎？

是的。本軟體採用 BSD-3-Clause 授權，無需訂閱，也沒有按分鐘計費的費用。Whisper 模型本身僅在初次啟動時下載一次（約 1-3 GB）；之後無須網路連線即可進行轉錄。

它會將我的音訊或影片上傳到任何地方嗎？

不會，預設不會。所有預設後端——faster-whisper、whisper.cpp、NVIDIA Parakeet——均在您的本機電腦上執行。僅有兩個後端為自選啟用（雲端 Gemini-API 後端與 Google Cloud Speech-to-Text），且在您親自於「進階」→「後端」啟用前，兩者均維持關閉。使用狀況統計（不包含音訊與檔案名稱）預設為開啟，可於「說明」→「使用狀況統計」中關閉；軟體每天會至 GitHub 檢查一次新版本，而 檔案 → 離線工作 則會停止所有網路連線。

它可以在哪些平台上執行？

Windows、macOS 與 Linux。官方發布的下載項目包含 Windows 安裝程式、Windows 可攜式 ZIP 檔以及 macOS DMG；Linux 則透過原始碼執行。

它可以產生哪些逐字稿格式？

srt vtt ass tsv txt json lrc md docx pdf，以及 oTranscribe、ELAN、InqScribe 與 Express Scribe。

它可以標記說話者是誰嗎？

支援——提供選用的說話者辨識（「辨識說話者」），並具備逐字時間戳記與時間範圍剪輯。

它可以轉錄麥克風即時收音或系統音訊嗎？

支援，可透過「即時」分頁——在發生的當下即時轉錄麥克風或系統音訊。

它可以下載並轉錄網路影片嗎（例如來自 YouTube 的影片）？

可以，支援任何 yt-dlp 支援的網站，並提供下載完成後自動轉錄的選用步驟。

它可以摘要逐字稿、整理待辦事項或回答相關問題嗎？

可以，透過逐字稿檢視器中選用的「AI 工具」分頁——包含摘要、待辦事項、提問功能，以及可產生雙語 .srt 的逐段翻譯。此功能預設關閉。

它可以複製聲音並讓它唸出新的文字嗎？

可以，透過選用的「複製您的聲音」分頁，完全在您的本機電腦上使用 OmniVoice (Apache-2.0) 執行。預設為關閉；可在安裝時選擇啟用，且您必須確認已取得複製參考聲音的授權許可。

這與直接呼叫 Whisper API 有何不同？

預設透過 faster-whisper 在本機執行模型，因此沒有按分鐘計費的 API 費用，也沒有任何音訊會離開您的電腦——除非您明確選擇使用兩種雲端後端之一。

同一個網路上的多人可以在不必每台電腦都安裝的情況下使用它嗎？

可以——Web/LAN 存取模式可將這台電腦轉變為轉錄網頁，供同網路上的其他裝置使用。

2.2 版有哪些新內容？

轉錄分頁上的引擎和模型選擇器改為「準確度等級」：選擇快速、平衡或最佳，應用程式會挑選適合你的語言和電腦的模型，全新安裝預設使用 Large v3 Turbo。較少用的選項收在更多選項裡。波斯語、中文、日語、德語、泰語、瑞典語和希伯來語有專為該語言訓練的模型；網頁 / 區域網路存取分頁會顯示 QR 碼，可用同一 Wi-Fi 下的手機傳送錄音；Windows 為波斯語、阿拉伯語和希伯來語鏡像整個視窗；雙語音訊以實驗性選項提供；下載表單也更精簡。全部 42 種介面語言皆已完整，並修正了 35 個錯誤。網站上還有一個能在瀏覽器中轉錄短檔案的頁面。2.1 版加入了 42 種介面語言、可靠的說話者標籤和更安全的儲存；2.0 版加入了佇列的速度與剩餘時間、透過連結取得附字幕的影片、存成單一離線網頁的逐字稿、可查證的「離線工作」模式，以及翻譯成英文。請見2.2 新功能和變更記錄。

它可以將影片連結轉換為帶有字幕的影片嗎？

可以。在「下載影片」分頁中，勾選 製作字幕影片：軟體會下載影片、使用 Whisper 進行轉錄，並以 ffmpeg 將字幕燒錄進影片中，產生一個以該影片命名並帶有 -subbed.mp4 的檔案。下載的原始檔案與逐字稿均會保留，且絕不會覆寫現有的 -subbed.mp4。

我可以讓這款應用程式完全不連網嗎？

可以。檔案 → 離線工作 會停止檢查更新、使用狀況統計、模型下載以及遠端 AI 提供者。開啟此模式時，視窗底部會有一行字顯示是否有連線開啟，且 立即驗證離線狀態 會顯示測試連線已被拒絕。關閉此模式時，軟體僅在啟動時讀取其線上設定、執行每日更新檢查、傳送使用狀況統計（可於「說明」→「使用狀況統計」關閉），以及進行您手動發起的下載。
