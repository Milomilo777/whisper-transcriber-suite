將 YouTube 影片轉為文字，免費且可離線使用

只需安裝一次的免費桌面應用程式（支援 Windows、macOS、Linux）。下載影片需要網際網路；轉錄本身則直接在您的電腦上執行。

若要將 YouTube 影片轉換為文字，只需將其連結貼入「下載影片」分頁，選擇文字格式，勾選「下載後轉錄」並按下「下載」。此軟體會使用開源下載工具 yt-dlp 擷取影片，並在您自己的電腦上透過 Whisper（語音辨識模型）進行轉錄，最後儲存為 TXT、DOCX、PDF 或 SRT 逐字稿。

不想安裝嗎？在瀏覽器中試用：一個免費頁面，直接在你的裝置上轉錄短檔案（最長 10 分鐘），不上傳、免註冊。較長的檔案請用下方的應用程式。

下載免費軟體

開始之前

請務必只從官方 GitHub 發行版本頁面下載安裝程式（首頁亦有連結）。由於未經程式碼簽署，Windows 在首次啟動時可能會發出警告：其他資訊 > 仍要執行。系統需求請參閱：安裝指南。

如何轉錄 YouTube 影片

  1. 僅限首次啟動。「快速開始」視窗會詢問您的語言以及選擇快速或最佳品質；語音模型僅在首次使用時下載一次。
  2. 開啟「下載影片」分頁，把 YouTube 連結貼到影片連結。應用程式會自動查詢可用格式和字幕。
  3. 選擇模式。音訊只儲存聲音，如果您只需要逐字稿，檔案更小且處理更快。音訊與影片則會一併保留畫面。
  4. 選填：展開表單下方的更多選項，用時間範圍（選填）只下載並轉錄一部分。格式為 H:MM:SS，兩個欄位都是 0:00:00 代表整支影片。設定範圍後，更多選項會自動展開。
  5. 下載前先選好檔案類型。切換到轉錄分頁，按一下進階設定…，在輸出格式下勾選TXT（或 DOCX、PDF）。預設是 SRT 加 JSON，得到的是字幕，而不是純文字檔。請保持勾選 JSON：應用程式用這個 JSON 檔來開啟逐字稿檢視器。該分頁上選擇的語言和準確度等級同樣適用於下載。
  6. 返回「下載影片」分頁，勾選「下載後轉錄」，接著點擊下載。
  7. 查看處理進度。表格中的該列會顯示進度條，而轉錄佇列分頁會顯示速度與剩餘時間。處理完成後，逐字稿會存放在來源檔案旁邊，且「轉錄」分頁上的最新結果卡片會提供開啟、檢視逐字稿以及儲存可分享頁面等選項。

影片已有字幕時更快速的處理方式

當查詢的影片已附帶字幕時，連結下方會出現一行綠色文字顯示有可用字幕，並會出現改用現有字幕按鈕。此功能會略過媒體下載與轉錄過程，直接擷取字幕並轉換為您選擇的格式。這只需要數秒而非數分鐘，但您取得的是既有字幕的原樣，而非由 Whisper 重新產生的逐字稿。若已勾選下載後轉錄，軟體會詢問您想使用哪一種方式，並可記住您的選擇。

其他網站與需要登入的影片

同一個下載器支援的任何網站，用法都一樣。對於需要帳號的影片，例如 Instagram、Facebook、TikTok 限時動態和有年齡限制的 YouTube 影片，請展開表單下方的更多選項，在登入 Cookie 下選擇你的瀏覽器。應用程式會讀取這台電腦上該瀏覽器的登入狀態，只在從該網站下載時使用，不會傳送到其他地方。並非所有受限影片都能成功。

實用須知

  • 沒有網路連線就無法下載。當開啟檔案 → 離線工作時，軟體會拒絕查詢連結，因此貼上連結前請先將該功能關閉。
  • YouTube 需要小型輔助工具。如果連結狀態旁顯示安裝 YouTube 輔助工具按鈕，請點擊一次。若沒有它，可能會遺失部分或全部 YouTube 格式並導致下載失敗。若因下載工具過舊而導致下載失敗，則會顯示更新提示列。

常見問題

這真的是免費的嗎？

是的：完全免費且開源，無需帳號、無需訂閱，也沒有每分鐘費用。

我的影片或逐字稿會被上傳到任何地方嗎？

使用預設引擎時不會：Whisper 會在您自己的電腦上執行，只有從影片網站下載時才會使用網路。雖然提供兩種雲端引擎，但在您自行開啟之前，它們都會保持關閉狀態。

它可以轉錄沒有字幕的影片，或是其他語言的影片嗎？

可以。Whisper 會直接辨識音訊，因此不需要字幕。您可以選擇所說的 語言，或保留為 自動。輸出：英文翻譯 會將非英文語音轉換為英文文字；此功能預設為關閉，且並非適用於所有引擎或模型。

我可以只轉錄長影片的其中一部分嗎？

可以。開啟「下載影片」分頁上的更多選項，在時間範圍（選填）以 H:MM:SS 填入起訖時間。只會下載這一段；如果勾選了「下載後轉錄」，也只會轉錄這一段。

我可以貼上整個播放清單嗎？

不行。每個任務僅處理一部影片。從播放清單中複製的連結只會下載該部影片，不會下載整個清單。
