Comment convertir gratuitement une vidéo en sous-titres SRT

Une application de bureau gratuite à installer une seule fois (Windows, macOS, Linux). Whisper, le modèle de reconnaissance vocale intégré, s'exécute sur votre ordinateur : avec les moteurs par défaut, votre vidéo n'est donc jamais envoyée en ligne.

Pour convertir une vidéo en sous-titres SRT, ouvrez l'onglet Transcrire, déposez un fichier vidéo ou audio, vérifiez que SRT est coché sous Paramètres avancés et cliquez sur Transcrire. Whisper génère le fichier SRT, le format de sous-titres standard, à côté du fichier d'origine, prêt pour un lecteur, un éditeur ou une mise en ligne. Pour un lien, consultez le guide YouTube.

Télécharger l'application gratuite

Avant de commencer

Les téléchargements se trouvent sur la page d'accueil ; les prérequis sont détaillés dans le guide d'installation. Utilisez uniquement la page officielle des versions sur GitHub : l'installateur n'étant pas signé numériquement, Windows peut afficher un avertissement au premier lancement (Informations complémentaires > Exécuter quand même).

1. Créer le SRT

  1. Ouvrez l'onglet Transcrire et glissez votre fichier vidéo ou audio dans la fenêtre, ou cliquez sur Parcourir les fichiers.... Vous pouvez sélectionner plusieurs fichiers à la fois.
  2. Définissez la Langue, ou laissez sur Auto pour la détecter automatiquement. La choisir vous-même est plus rapide et peut s'avérer plus précis pour les extraits courts ou bruités.
  3. Facultatif : renseignez la Plage horaire (H:MM:SS) pour ne transcrire qu'une partie du fichier.
  4. Choisissez les formats de sous-titres. Cliquez sur Paramètres avancés… et repérez Formats de sortie. SRT et JSON sont sélectionnés par défaut. Cochez VTT (le format de sous-titres web) pour les vidéos sur le web, ou ASS (sous-titres stylisés / karaoké) si vous mettez en forme vos sous-titres dans un éditeur. Chaque format coché est généré pour chaque tâche. Laissez JSON coché : l'application utilise ce fichier JSON pour ouvrir le visualiseur de transcription.
  5. Facultatif : cochez Horodatage par mot pour enregistrer l'heure de début et de fin de chaque mot ; les fichiers seront plus volumineux. Vos sous-titres SRT continuent de suivre des segments entiers, un sous-titre par segment de parole. L'horodatage des mots est utilisé par les formats VTT et ASS pour le surlignage de type karaoké.
  6. Cliquez sur Transcrire. Suivez la tâche dans l'onglet File d'attente de transcription. Le fichier de sous-titres est créé à côté de votre fichier d'origine avec le même nom et une nouvelle extension (par exemple talk.mp4 devient talk.srt), et la carte Dernier résultat propose un bouton Ouvrir pour chaque fichier.

Sous-titres dans une autre langue

Pour obtenir des sous-titres en anglais à partir de paroles dans une autre langue, cochez Sortie : traduction anglaise ; les fichiers porteront la mention .en-translated dans leur nom. Cette option est désactivée par défaut et ne fonctionne pas avec tous les moteurs ou modèles. Pour les autres langues, un onglet optionnel Outils IA dans le visualiseur de transcription permet de générer un fichier SRT bilingue une fois son module IA configuré (un modèle local que vous installez, ou un fournisseur en ligne de votre choix) ; il est désactivé par défaut.

2. Corriger (facultatif)

Ouvrez Voir la transcription depuis la carte Dernier résultat (nécessite la sortie JSON, cochée par défaut). Rechercher et remplacer et Supprimer les mots de remplissage permettent de modifier le texte ; pour des modifications ligne par ligne, utilisez n'importe quel éditeur de sous-titres. Faites un clic droit sur un segment et choisissez Modifier l'horodatage... pour ajuster le début et la fin de ce seul segment ; les autres segments ne sont pas modifiés.

Cliquez sur Enregistrer les modifications (Ctrl+S) : l'application enregistre la transcription, puis recrée et remplace le fichier .srt ainsi que les autres fichiers texte voisins à partir de la transcription modifiée. Tout fichier modifié par ailleurs reste inchangé, et l'application indique qu'il contient toujours l'ancien texte. Un PDF n'est jamais recréé. Sous Windows, Ouvrir dans Subtitle Edit ouvre le fichier de sous-titres dans cet éditeur gratuit, qui dispose d'une vue en forme d'onde pour affiner le minutage.

3. Incruster les sous-titres (facultatif)

À partir d'un lien : laissez le mode sur Audio et vidéo, cochez Créer une vidéo sous-titrée et cliquez sur Télécharger. L'application télécharge le média, le transcrit et incruste les sous-titres dans un nouveau fichier portant le nom de la vidéo suivi de -subbed.mp4. Le téléchargement et la transcription sont conservés, et un fichier -subbed.mp4 existant n'est jamais écrasé.

À partir d'un fichier déjà transcrit : ouvrez l'onglet File d'attente de transcription, faites un clic droit sur la ligne terminée et choisissez Incruster les sous-titres dans la vidéo.... Cette opération nécessite un SRT, veillez donc à laisser SRT coché sous Formats de sortie. Le résultat est un fichier MP4 lisible sur téléphones, téléviseurs et navigateurs. Le réencodage prend du temps, dont la durée dépend des performances de votre ordinateur.

Bon à savoir

  • Minutage. Les temps du SRT suivent les segments de Whisper. L'option Affiner le minutage des mots avec stable-ts (plus lent) dans les Paramètres avancés est une étape supplémentaire facultative qui précise l'horodatage des mots ; elle télécharge un composant lors de sa première utilisation.
  • Vérifiez avant de publier. L'application signale les phrases répétées ou inventées, mais les noms propres et les chiffres méritent toujours une relecture.

Questions

Quels formats de sous-titres génère-t-elle ?

SRT, VTT et ASS, ainsi que TSV, TXT, JSON, LRC, Markdown, DOCX et PDF, sans oublier les formats oTranscribe, ELAN, InqScribe et Express Scribe.

Comment ajouter le fichier SRT sur YouTube ou dans un éditeur vidéo ?

Téléversez ou importez le fichier .srt en tant que fichier de sous-titres. L'application l'enregistre à côté de votre vidéo, avec le même nom et l'extension .srt.

Ma vidéo est-elle téléversée ?

Non, pas avec les moteurs par défaut. Deux moteurs dans le cloud existent mais restent désactivés tant que vous ne les activez pas vous-même, et Fichier → Travailler hors ligne bloque toute utilisation du réseau.
