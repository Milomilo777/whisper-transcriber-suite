Cum funcționează

Rulează pe computerul dumneavoastră. Fișierele audio rămân acolo.

Transcrierea rulează pe propriul computer. Fișierele audio sunt încărcate doar dacă activați unul dintre cele două motoare cloud opționale, iar textul transcrierii este transmis doar dacă conectați personal un model AI la distanță.

  1. 01

    Trageți un fișier sau lipiți un link

    Fișiere audio sau video de pe disc sau orice poate prelua yt-dlp. Interfața Tk rulează în procesul principal și adaugă sarcina în coadă instantaneu.

  2. 02

    Un worker păstrează modelul

    Fiecare sarcină rulează în propriul subproces worker de lungă durată, care păstrează Whisper în memorie și transmite progresul prin JSON delimitat prin linii noi — astfel încât fereastra nu se blochează niciodată.

  3. 03

    Transcrierea este salvată chiar lângă fișierul dumneavoastră

    Un token per worker și un semnal de tip heartbeat mențin rutarea robustă și permit aplicației să detecteze un worker blocat în loc să se blocheze odată cu el.

Fișierele descărcate prin curl nu sunt puse în carantină, așa că nu există niciun avertisment „unidentified developer” peste care să trebuiască să treceți.

A=x64; [ "$(uname -m)" = arm64 ] && [ "$(sw_vers -productVersion | cut -d. -f1)" -ge 14 ] && A=arm64; curl -fL -o /tmp/wts.dmg "https://github.com/Milomilo777/whisper-transcriber-suite/releases/download/v2.2.0/WhisperTranscriberSuite-v2.2.0-macOS-$A.dmg" && hdiutil attach -nobrowse -quiet -mountpoint /tmp/wts-dmg /tmp/wts.dmg && cp -R "/tmp/wts-dmg/Whisper Transcriber Suite.app" /Applications/ && hdiutil detach -quiet /tmp/wts-dmg && rm /tmp/wts.dmg && open "/Applications/Whisper Transcriber Suite.app"

Preferați metoda obișnuită? Deschideți .dmg și trageți aplicația în Applications; la prima lansare este apoi necesar clic dreapta → Open (macOS 14 și versiunile mai vechi) sau System Settings → Privacy & Security → Open Anyway (macOS 15+).

FAQ

Întrebări frecvente

Aveți și alte întrebări? Întrebați în GitHub Discussions.

Este Whisper Transcriber Suite gratuit?

Da. Este licențiat sub BSD-3-Clause, fără abonamente și fără costuri pe minut. Modelul Whisper se descarcă o singură dată (aproximativ 1-3 GB) la prima lansare; după aceea, transcrierea funcționează fără conexiune la internet.

Încarcă fișierele mele audio sau video undeva?

Nu, nu în mod implicit. Fiecare backend implicit — faster-whisper, whisper.cpp, NVIDIA Parakeet — rulează local pe computerul dvs. Două backend-uri sunt strict opționale (un backend cloud Gemini-API și Google Cloud Speech-to-Text), și ambele rămân dezactivate până când le activați dvs. în Advanced → Backend. Statisticile de utilizare (fără conținut audio, fără nume de fișiere) sunt activate în mod implicit și pot fi dezactivate din Ajutor → Statistici de utilizare; aplicația verifică pe GitHub o dată pe zi dacă există o versiune nouă, iar Fișier → Lucru offline oprește orice utilizare a rețelei.

Pe ce platforme rulează?

Windows, macOS și Linux. Descărcările publicate sunt un program de instalare pentru Windows, o arhivă ZIP portabilă pentru Windows și un fișier DMG pentru macOS; Linux rulează din sursă.

Ce formate de transcriere poate genera?

srt vtt ass tsv txt json lrc md docx pdf, plus oTranscribe, ELAN, InqScribe și Express Scribe.

Poate eticheta cine vorbește?

Da — diarizare opțională a vorbitorilor („Identifică vorbitorii”), cu marcaje temporale pentru fiecare cuvânt și decupare pe intervale de timp.

Poate transcrie live un microfon sau sunetul de sistem?

Da, din fila Live — un microfon sau sunetul sistemului, transcrise în timp real.

Poate descărca și transcrie videoclipuri online, de exemplu de pe YouTube?

Da, de pe orice site acceptat de yt-dlp, cu o etapă opțională de transcriere la finalizare.

Poate rezuma o transcriere, extrage puncte de acțiune sau răspunde la întrebări despre aceasta?

Da, prin fila opțională Instrumente AI din vizualizatorul de transcriere — rezumare, acțiuni de urmat, adresarea unei întrebări și o etapă de traducere segment cu segment care generează un .srt bilingv. Este dezactivată în mod implicit.

Poate clona o voce pentru a o face să rostească un text nou?

Da, prin fila opțională Clonează-ți vocea, folosind OmniVoice (Apache-2.0) în întregime pe computerul dvs. Este dezactivată în mod implicit; o puteți activa la instalare și trebuie să confirmați că aveți permisiunea de a clona vocea de referință.

Prin ce diferă acest lucru de apelarea directă a API-ului Whisper?

Rulează modelul local prin faster-whisper în mod implicit, astfel că nu există costuri API pe minut și niciun conținut audio nu părăsește computerul dvs. — cu excepția cazului în care activați explicit unul dintre cele două backend-uri din cloud.

Pot mai multe persoane din aceeași rețea să o folosească fără a o instala pe fiecare computer?

Da — modul de acces Web/LAN transformă acest computer într-o pagină de transcriere pe care o pot utiliza și celelalte dispozitive din rețea.

Opțiunile mai rare se află la Mai multe opțiuni. Persana, chineza, japoneza, germana, thailandeza, suedeza și ebraica primesc modele antrenate pentru limba respectivă. Versiunea 2.1 a adus interfața în 42 de limbi, etichete de vorbitor fiabile și salvare mai sigură; versiunea 2.0 a adus viteza și timpul rămas din coadă, videoclip cu subtitrări dintr-un link, transcrieri ca o singură pagină web offline, un mod Lucru offline verificabil și traducerea în engleză. Vedeți Ce este nou în 2.2 și jurnalul de modificări.

Poate transforma un link video într-un videoclip cu subtitrări?

Da. În fila Descărcare videoclipuri, bifați Creează videoclip subtitrat: aplicația descarcă videoclipul, îl transcrie cu Whisper și încorporează subtitrările cu ffmpeg, generând un fișier denumit după videoclip cu -subbed.mp4. Descărcarea și transcrierea sunt păstrate, iar un -subbed.mp4 existent nu este înlocuit niciodată.

Pot păstra aplicația complet deconectată de la rețea?

Da. Fișier → Lucru offline oprește verificarea actualizărilor, statisticile de utilizare, descărcările de modele și furnizorii AI la distanță. Cât timp este activat, o linie din partea de jos a ferestrei indică dacă o conexiune este deschisă, iar Verificați offline acum arată cum conexiunile de test sunt refuzate. Când este dezactivat, aplicația accesează rețeaua doar pentru setările sale online la pornire, verificarea zilnică a actualizărilor, statisticile de utilizare (care pot fi dezactivate din Ajutor → Statistici de utilizare) și descărcările pe care le inițiați.

Cum pot contacta proiectul?

Raportările de erori și propunerile de funcționalități se trimit pe GitHub Issues, întrebările pe Discussions, iar orice altceva prin e-mail (adresa este afișată la cerere în secțiunea Contact). Rapoartele de securitate se transmit prin sistemul privat de raportare a vulnerabilităților de pe GitHub.
