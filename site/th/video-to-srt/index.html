วิธีแปลงวิดีโอเป็นคำบรรยาย SRT ฟรี

แอปเดสก์ท็อปฟรีที่ติดตั้งครั้งเดียว (Windows, macOS, Linux) Whisper โมเดลจดจำคำพูดที่อยู่ภายใน ทำงานบนคอมพิวเตอร์ของคุณ ดังนั้นด้วยเอนจินเริ่มต้น วิดีโอของคุณจะไม่ถูกอัปโหลด

ในการแปลงวิดีโอเป็นคำบรรยาย SRT ให้เปิดแท็บถอดเสียง ลากไฟล์วิดีโอหรือเสียงมาวาง ตรวจสอบว่าติ๊ก SRT ใต้การตั้งค่าขั้นสูงแล้วกดถอดเสียง Whisper จะเขียนไฟล์ SRT ซึ่งเป็นรูปแบบไฟล์คำบรรยายทั่วไป ไว้ข้างไฟล์ต้นฉบับ พร้อมใช้งานสำหรับเครื่องเล่น โปรแกรมตัดต่อ หรืออัปโหลด สำหรับลิงก์ ดูคู่มือ YouTube

ดาวน์โหลดแอปฟรี

ก่อนเริ่มต้น

ดาวน์โหลดได้จากหน้าหลัก ส่วนข้อกำหนดอยู่ในคู่มือติดตั้ง ใช้หน้ารีลีส GitHub อย่างเป็นทางการเท่านั้น: ตัวติดตั้งไม่ได้ลงนามโค้ด ดังนั้น Windows อาจเตือนในการเปิดครั้งแรก (ข้อมูลเพิ่มเติม > เรียกใช้ต่อไป)

1. สร้างไฟล์ SRT

  1. เปิดแท็บถอดเสียงและลากไฟล์วิดีโอหรือเสียงของคุณไปยังหน้าต่าง หรือคลิกเรียกดูไฟล์... คุณสามารถเลือกไฟล์ได้หลายไฟล์พร้อมกัน
  2. ตั้งค่าภาษา หรือปล่อยเป็นอัตโนมัติเพื่อตรวจจับ เลือกเองจะเร็วกว่าและอาจแม่นยำกว่าสำหรับคลิปสั้น ๆ หรือมีเสียงรบกวน
  3. ไม่บังคับ: กรอกช่วงเวลา (H:MM:SS) เพื่อถอดเสียงเฉพาะบางส่วนของไฟล์
  4. เลือกรูปแบบคำบรรยาย คลิกการตั้งค่าขั้นสูง…และมองหารูปแบบผลลัพธ์ ค่าเริ่มต้นคือ SRT และ JSON ติ๊กVTT (รูปแบบคำบรรยายสำหรับเว็บ) สำหรับวิดีโอเว็บ หรือASS (คำบรรยายมีสไตล์ / คาราโอเกะ)หากคุณตกแต่งคำบรรยายในโปรแกรมตัดต่อ ทุกรูปแบบที่ติ๊กจะถูกเขียนสำหรับทุกงาน ควรติ๊ก JSON ไว้: เป็นไฟล์ JSON ที่แอปใช้เปิดตัวดูข้อความถอดเสียง
  5. ไม่บังคับ: ติ๊กเวลาประทับระดับคำเพื่อเก็บเวลาเริ่มต้นและสิ้นสุดของทุกคำ ไฟล์จะมีขนาดใหญ่ขึ้น คิว SRT ของคุณยังคงตามส่วนทั้งส่วน คิวละส่วนของคำพูด การกำหนดเวลาระดับคำจะถูกใช้โดย VTT และ ASS สำหรับการไฮไลต์แบบคาราโอเกะ
  6. คลิกถอดเสียง ติดตามงานในแท็บคิวการถอดเสียง ไฟล์คำบรรยายจะอยู่ข้างไฟล์ต้นฉบับพร้อมชื่อเดียวกันและนามสกุลใหม่ ตัวอย่างเช่น talk.mp4 กลายเป็น talk.srt และการ์ดผลลัพธ์ล่าสุดจะมีปุ่มเปิดสำหรับแต่ละไฟล์

คำบรรยายในภาษาอื่น

สำหรับคำบรรยายภาษาอังกฤษจากคำพูดที่ไม่ใช่ภาษาอังกฤษ ให้ติ๊กผลลัพธ์: คำแปลภาษาอังกฤษ ไฟล์จะมีชื่อต่อท้ายด้วย .en-translated ค่าเริ่มต้นจะปิดอยู่และใช้ไม่ได้กับทุกเอนจินหรือโมเดล สำหรับภาษาอื่น แท็บเครื่องมือ AI ในตัวดูข้อความถอดเสียงสามารถเขียน SRT สองภาษาได้เมื่อคุณตั้งค่าเลเยอร์ AI (โมเดลในเครื่องที่คุณติดตั้ง หรือผู้ให้บริการออนไลน์ที่คุณเลือก) ค่าเริ่มต้นจะปิดอยู่

2. แก้ไข (ไม่บังคับ)

เปิดดูข้อความถอดเสียงจากการ์ดผลลัพธ์ล่าสุด (ต้องมีผลลัพธ์ JSON ซึ่งติ๊กไว้เป็นค่าเริ่มต้น) ค้นหาและแทนที่และลบคำเติมจะเปลี่ยนข้อความ สำหรับการแก้ไขทีละบรรทัด ให้ใช้โปรแกรมแก้ไขคำบรรยายใดก็ได้ คลิกขวาที่ส่วนใดส่วนหนึ่งและเลือกแก้ไขเวลาประทับ...เพื่อเปลี่ยนจุดเริ่มต้นและสิ้นสุดของส่วนนั้น ส่วนอื่น ๆ จะไม่ขยับ

คลิกบันทึกการเปลี่ยนแปลง (Ctrl+S): แอปจะบันทึกข้อความถอดเสียง จากนั้นสร้างไฟล์ .srt และไฟล์ข้อความอื่น ๆ ข้าง ๆ ใหม่จากข้อความถอดเสียงที่แก้ไขแล้ว โดยแทนที่ของเดิม ไฟล์ที่คุณเปลี่ยนที่อื่นจะไม่ถูกแตะ และแอปจะแจ้งว่ายังคงมีข้อความเดิมอยู่ PDF จะไม่ถูกสร้างใหม่ บน Windows เปิดใน Subtitle Editจะเปิดไฟล์คำบรรยายในโปรแกรมแก้ไขฟรีนั้น ซึ่งมีมุมมองคลื่นเสียงสำหรับปรับเวลาอย่างละเอียด

3. ฝังคำบรรยาย (ไม่บังคับ)

จากลิงก์: คงโหมดไว้ที่เสียงและวิดีโอ ติ๊กสร้างวิดีโอพร้อมคำบรรยายและคลิกดาวน์โหลด แอปจะดาวน์โหลด ถอดเสียง และวาดคำบรรยายลงในไฟล์ใหม่ที่ตั้งชื่อตามวิดีโอพร้อมต่อท้ายด้วย -subbed.mp4 ไฟล์ที่ดาวน์โหลดและข้อความถอดเสียงจะถูกเก็บไว้ และไฟล์ -subbed.mp4 ที่มีอยู่จะไม่ถูกแทนที่

จากไฟล์ที่คุณถอดเสียงแล้ว: เปิดแท็บคิวการถอดเสียง คลิกขวาที่แถวที่เสร็จสิ้นและเลือกฝังคำบรรยายลงในวิดีโอ... ต้องมีไฟล์ SRT ดังนั้นให้ติ๊ก SRT ไว้ใต้รูปแบบผลลัพธ์ ผลลัพธ์คือไฟล์ MP4 ที่โทรศัพท์ ทีวี และเบราว์เซอร์เล่นได้ การเข้ารหัสใหม่ใช้เวลาสักครู่ นานแค่ไหนขึ้นอยู่กับคอมพิวเตอร์ของคุณ

ควรทราบ

  • การกำหนดเวลา เวลา SRT ตามส่วนของ Whisper ปรับเวลาระดับคำให้ละเอียดด้วย stable-ts (ช้ากว่า)ในการตั้งค่าขั้นสูงเป็นขั้นตอนเพิ่มเติมที่ไม่บังคับ ซึ่งจะทำให้การกำหนดเวลาระดับคำคมชัดขึ้น โดยจะดาวน์โหลดคอมโพเนนต์ในครั้งแรก
  • ตรวจสอบก่อนเผยแพร่ แอปจะทำเครื่องหมายบรรทัดที่ซ้ำหรือแต่งขึ้น แต่ชื่อและตัวเลขยังคงควรตรวจอ่าน

คำถาม

แอปเขียนคำบรรยายรูปแบบใดบ้าง?

SRT, VTT และ ASS รวมถึง TSV, TXT, JSON, LRC, Markdown, DOCX และ PDF และรูปแบบ oTranscribe, ELAN, InqScribe และ Express Scribe

ฉันเพิ่มไฟล์ SRT ลงใน YouTube หรือโปรแกรมตัดต่อวิดีโอได้อย่างไร?

อัปโหลดหรือนำเข้าไฟล์ .srt เป็นไฟล์คำบรรยาย แอปจะเขียนไฟล์นั้นไว้ข้างวิดีโอของคุณ พร้อมชื่อเดียวกันและนามสกุล .srt

วิดีโอของฉันถูกอัปโหลดไหม?

ไม่ ไม่ใช่กับเอนจินเริ่มต้น มีเอนจินคลาวด์อยู่สองตัวแต่จะปิดอยู่จนกว่าคุณจะเปิดใช้งานเอง และไฟล์ → ทำงานออฟไลน์จะหยุดการใช้เครือข่ายทั้งหมด
