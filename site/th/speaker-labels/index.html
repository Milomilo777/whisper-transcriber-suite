หน้าหลัก › ป้ายผู้พูด

ถอดเสียงสัมภาษณ์พร้อมป้ายผู้พูด (ใครพูดอะไร)

แอปเดสก์ท็อปฟรีที่ติดตั้งครั้งเดียว (Windows, macOS, Linux) บันทึกของคุณจะถูกประมวลผลบนคอมพิวเตอร์ของคุณ และไม่ต้องมีบัญชี

แอปแยกเสียงของแต่ละคนและติดป้ายว่า ผู้พูด 00 ผู้พูด 01 และต่อไปเรื่อย ๆ แอปไม่รู้ว่าใครเป็นใครจนกว่าคุณจะเปลี่ยนชื่อ เสียงที่คล้ายกัน คำตอบสั้น ๆ การพูดซ้อนกัน และเสียงรบกวนพื้นหลังอาจทำให้ติดป้ายผิด วิธีเริ่ม: เปิดตัวเลือกเพิ่มเติมในแท็บถอดเสียง ติ๊กระบุผู้พูด แล้วกดถอดเสียง

ไม่อยากติดตั้ง? ลองใช้ในเบราว์เซอร์ของคุณ: หน้าฟรีที่ถอดเสียงไฟล์สั้น (ไม่เกิน 10 นาที) บนอุปกรณ์ของคุณเอง ไม่ต้องอัปโหลด ไม่ต้องสมัคร ส่วนแอปด้านล่างรองรับไฟล์ที่ยาวกว่า

ดาวน์โหลดแอปฟรี

ก่อนเริ่มต้น

เวอร์ชัน Windows และ Mac มีโมเดลตรวจจับผู้พูดมาให้ ดาวน์โหลดแอปจากหน้ารีลีส GitHub อย่างเป็นทางการเท่านั้น ตัวติดตั้งไม่ได้ลงนามโค้ด ดังนั้น Windows อาจเตือน (ข้อมูลเพิ่มเติม > เรียกใช้ต่อไป) ดูเพิ่มเติมได้ที่หน้าหลักและคู่มือติดตั้ง

วิธีเพิ่มป้ายผู้พูดลงในข้อความถอดเสียง

  1. เพิ่มบันทึกเสียง ในแท็บถอดเสียง ลากไฟล์เสียงหรือวิดีโอเข้ามา หรือคลิกเรียกดูไฟล์... ลิงก์จากแท็บดาวน์โหลดวิดีโอก็ใช้ได้เช่นกัน เพราะใช้การตั้งค่าถอดเสียงเดียวกัน
  2. เลือกภาษา หรือปล่อยเป็นอัตโนมัติ
  3. เปิดตัวเลือกเพิ่มเติมแล้วติ๊กระบุผู้พูด ถ้าช่องขึ้นว่า ระบุผู้พูด (ใช้ไม่ได้) ให้เลื่อนเมาส์ไปชี้เพื่อดูสาเหตุ ตัวเลือกผู้พูดด้านล่างจะใช้งานได้: ปล่อยเป็นอัตโนมัติ หรือเลือกตัวเลขตั้งแต่ 2 ถึง 10 เพื่อกำหนดจำนวนคนให้ตรงตามนั้น
  4. ไม่บังคับ: ในตัวเลือกเพิ่มเติม ติ๊กเวลาประทับระดับคำเพื่อเก็บเวลาเริ่มและจบของทุกคำ ไม่ใช่แค่ทุกประโยค ผลลัพธ์จะใหญ่ขึ้น
  5. เลือกรูปแบบส่งออก คลิกการตั้งค่าขั้นสูง…และติ๊กDOCXและPDFใต้รูปแบบผลลัพธ์ SRT, TXT, Markdown และ JSON ก็มีป้ายผู้พูดด้วย ควรติ๊ก JSON ไว้: เป็นไฟล์ JSON ที่แอปใช้เปิดตัวดูข้อความถอดเสียง ซึ่งคุณต้องใช้ในขั้นตอนสุดท้าย
  6. คลิกถอดเสียง การตรวจจับผู้พูดจะทำงานหลังการถอดเสียงและเพิ่มเวลาประมวลผล จากนั้นเปิดดูข้อความถอดเสียงจากการ์ดผลลัพธ์ล่าสุด
  7. แทนที่ป้ายทั่วไปด้วยชื่อ ในตัวดู ให้คลิกขวาที่เซลล์ในคอลัมน์ผู้พูด เลือกเปลี่ยนชื่อ 'Speaker 00' (ทุกที่)... พิมพ์ชื่อและคลิกบันทึกการเปลี่ยนแปลง (Ctrl+S) ไฟล์ Word และข้อความข้าง ๆ จะถูกสร้างใหม่เมื่อยังตรงกับข้อความถอดเสียงต้นฉบับ ส่วน PDF จะไม่ถูกสร้างใหม่ ดังนั้นให้ส่งออกใหม่หลังเปลี่ยนชื่อ

หน้าตาของป้ายผู้พูด

แต่ละส่วนจะเริ่มต้นด้วยผู้พูดของส่วนนั้น ในข้อความถอดเสียง Word หรือ PDF บรรทัดจะประกอบด้วยเวลาประทับ ผู้พูดในตัวหนา แล้วตามด้วยข้อความ SRT, VTT และ TXT จะวางSpeaker 00:ไว้หน้าข้อความ ASS เก็บไว้ในฟิลด์ชื่อของตัวเอง และ JSON เก็บเป็นฟิลด์ผู้พูด หน้าเว็บที่แชร์ได้ก็แสดงเช่นกัน บรรทัดด้านล่างเป็นตัวอย่างการจัดวาง ไม่ใช่ผลลัพธ์จริง:

[00:00:04]  Speaker 00:  So where do we start?
[00:00:07]  Speaker 01:  With the recording itself.

ควรทราบ

  • ป้ายละส่วน แต่ละส่วนของข้อความถอดเสียงจะได้ผู้พูดที่คำพูดที่ตรวจจับได้ทับซ้อนกับส่วนนั้นมากที่สุด หากมีสองคนพูดภายในส่วนเดียวกัน หรือพูดทับซ้อนกัน ส่วนทั้งส่วนจะมีป้ายเดียว ส่วนที่ไม่มีคำพูดที่ตรวจจับได้ทับซ้อนจะไม่มีป้าย
  • การแก้ไขบรรทัดเดียว การเปลี่ยนชื่อจะเปลี่ยนทุกบรรทัดที่มีป้ายนั้นพร้อมกัน ตัวดูไม่มีวิธีเปลี่ยนผู้พูดของบรรทัดเดียว ดังนั้นให้แก้บรรทัดเดียวด้วยมือในไฟล์ Word หรือข้อความที่ส่งออก
  • ชื่อทั่วไป ป้ายจะมีเลขกำกับ และเลขจะคงที่ภายในไฟล์เดียวแต่ไม่ข้ามไฟล์
  • หากจำนวนดูผิด ให้ตั้งค่าผู้พูดเป็นจำนวนคนจริงแทนที่จะปล่อยเป็นอัตโนมัติ
  • ออฟไลน์ ไม่ต้องมีบัญชี Hugging Face ทำงานบนคอมพิวเตอร์ของคุณเอง และใช้เวลาเพิ่มเติมจากการถอดเสียง
  • การกำหนดเวลาระดับคำ เวลาประทับระดับคำจะถูกเก็บในไฟล์ JSON และใช้สำหรับการไฮไลต์แบบคาราโอเกะใน VTT และ ASS

คำถาม

แอประบุชื่อผู้พูดให้ไหม?

ไม่ได้โดยค่าเริ่มต้น ป้ายจะแสดงเป็น Speaker 00, Speaker 01 ไปเรื่อยๆ ใช้ตัวเลือกเปลี่ยนชื่อในตัวดูบทถอดเสียงเพื่อเปลี่ยนเป็นชื่อจริงได้

แยกผู้พูดได้กี่คน?

ตั้ง Speakers ไว้ที่ Auto แล้วแอปจะตัดสินใจเอง หรือระบุจำนวน 2 ถึง 10 ได้หากทราบแน่ชัด

แยกคนที่พูดพร้อมกันได้ไหม?

ไม่ได้ การพูดทับซ้อนกันจะไม่ถูกแยก แต่ละช่วงจะมีป้ายเดียวคือผู้พูดที่พูดเป็นส่วนใหญ่ในช่วงนั้น ตรวจสอบช่วงดังกล่าวได้ด้วยการฟัง

รูปแบบส่งออกใดที่แสดงป้ายผู้พูดบ้าง?

DOCX, PDF, SRT, VTT, TXT, Markdown, ASS, JSON และหน้าเว็บที่แชร์ได้
