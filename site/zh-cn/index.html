工作原理

在您的电脑上运行。您的音频文件将保留在本地。

转录在您自己的电脑上运行。只有在您开启两个可选的云引擎之一时，音频才会上传；只有在您自行连接远程 AI 模型时，转录文本才会发出。

  1. 01

    拖入文件，或粘贴链接

    来自磁盘的音频或视频，或任何 yt-dlp 可以获取的内容。Tk 界面在主进程中运行并立即将任务加入队列。

  2. 02

    工作进程持有模型

    每个任务都在其专属的长期工作进程中运行，该进程将 Whisper 保留在内存中，并通过换行符分隔的 JSON 流式传回进度——因此窗口绝不会卡死。

  3. 03

    转录文件生成在您的文件旁边

    每个工作进程的令牌和心跳机制确保了路由的稳健性，让应用能够检测到卡死的工作进程，而不是随之一起卡死。

基于 OpenAI 的 Whisper 语音识别模型构建，通过 faster-whisper、whisper.cpp 或 NVIDIA Parakeet 在本地运行，并使用 yt-dlp 和 FFmpeg 处理媒体。

常见问题

常见问题解答

还有其他问题？在 GitHub Discussions 中提问。

Whisper Transcriber Suite 是免费的吗？

是的。它采用 BSD-3-Clause 许可，无需订阅，也没有按分钟计费。Whisper 模型本身会在首次启动时下载一次（约 1-3 GB）；此后，转录无需互联网连接即可工作。

它会把我的音频或视频上传到任何地方吗？

默认情况下不会。每个默认后端 —— faster-whisper、whisper.cpp、NVIDIA Parakeet —— 都在你的本机上运行。两个后端是可选的（云端 Gemini-API 后端和 Google Cloud Speech-to-Text），在你自行在“高级” → “后端”中启用之前，它们都会保持关闭。使用情况统计（不含音频和文件名）默认开启，可在“帮助” → “使用情况统计”下关闭；应用每天检查一次 GitHub 以获取新版本，而 文件 → 离线工作 会停止所有网络使用。

它可以在哪些平台上运行？

Windows、macOS 和 Linux。已发布的下载包括 Windows 安装程序、Windows 便携版 ZIP 和 macOS DMG；Linux 从源码运行。

它可以生成哪些转录格式？

srt vtt ass tsv txt json lrc md docx pdf，以及 oTranscribe、ELAN、InqScribe 和 Express Scribe。

它可以标记谁在说话吗？

是 —— 可选的说话人分离（“识别说话人”），带有逐词时间戳和时间范围裁剪。

它可以转录实时麦克风或系统音频吗？

是，在“实时”选项卡中 —— 支持麦克风或系统音频，实时进行转录。

它可以下载并转录在线视频（例如来自 YouTube 的视频）吗？

可以，支持 yt-dlp 支持的任何网站，并带有可选的完成后转录步骤。

它可以总结转录文本、提取待办事项或回答关于它的问题吗？

是，通过转录查看器中可选的“AI 工具”选项卡 —— 摘要、行动项、提问，以及为每个片段生成双语 .srt 的翻译过程。默认关闭。

它可以克隆声音并让它说出新文本吗？

是，通过可选的“克隆你的声音”选项卡，完全在你的机器上使用 OmniVoice (Apache-2.0)。默认关闭；在安装时选择启用，并且你必须确认已获得克隆参考声音的许可。

这与直接调用 Whisper API 有什么不同？

它默认通过 faster-whisper 在本地运行模型，因此没有按分钟计费的 API 成本，音频也不会离开你的设备 —— 除非你明确选择启用两个云端后端之一。

同一网络上的几个人能否在不将其安装到每台机器上的情况下使用它？

是 —— Web/局域网访问模式可将此设备变为一个转录页面，供网络上的其他设备使用。

What is new in version 2.2?

Accuracy levels replace the engine and model pickers on the Transcribe tab: choose Fast, Balanced or Best and the app picks a model that fits your language and computer, and new installs start on Large v3 Turbo. The rarer options sit under More options. Persian, Chinese, Japanese, German, Thai, Swedish and Hebrew get models trained for that language; the Web / LAN access tab shows a QR code so you can send a recording from a phone on the same Wi-Fi; Windows mirrors the window for Persian, Arabic and Hebrew; two-language audio is available as an experimental option; and the Download form is more compact. All 42 interface languages are complete and 35 bugs were fixed. The site also has a page that transcribes a short file in your browser. 它可以把视频链接变成带字幕的视频吗？

是。在“下载视频”选项卡上，勾选 生成字幕视频：应用下载视频，使用 Whisper 进行转录，并用 ffmpeg 将字幕烧录进去，生成一个以视频命名的文件，扩展名为 -subbed.mp4。下载的文件和转录文本会被保留，且永远不会替换已有的 -subbed.mp4。

我可以让应用完全断开网络吗？

是。文件 → 离线工作 会停止更新检查、使用情况统计、模型下载和远程 AI 提供商。开启此功能时，窗口底部会显示当前是否建立了连接，而 立即验证离线状态 会显示测试连接被拒绝的情况。关闭此功能时，应用仅在启动时获取在线设置、进行每日更新检查、收集使用情况统计（可在“帮助” → “使用情况统计”下关闭）以及你主动发起下载时连接网络。
