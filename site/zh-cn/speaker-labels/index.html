转录采访并添加说话人标签（谁说了什么）

一款安装一次即可使用的免费桌面应用（支持 Windows、macOS、Linux）。你的录音会在你的电脑上处理，无需账户。

应用会区分不同的声音并将其标记为 Speaker 00、Speaker 01 等。在你重命名之前，它不知道任何人是谁。相似的声音、简短的回答、重叠的语音和背景噪音可能导致标签错误。要开始使用，请在“转录”选项卡上勾选“识别说话人”并点击“转录”。

下载免费应用

开始之前

Windows 和 Mac 版本内置了说话人检测模型。请仅从GitHub 官方发布页面获取应用；安装包未进行代码签名，因此 Windows 可能会发出警告（更多信息 > 仍要运行）。另请参阅主页和安装指南。

如何为转录文本添加说话人标签

  1. 添加录音。在转录选项卡上，拖入音频或视频文件，或点击浏览文件...。从下载视频选项卡获取的链接也可以，因为它使用相同的转录设置。
  2. 选择语言，或保持自动。
  3. 勾选“识别说话人”。如果复选框显示为识别说话人（不可用），请将鼠标悬停在上面查看原因。其下方的说话人选择器会开启：保持自动，或选择 2 到 10 之间的数字以强制指定人数。
  4. 可选：勾选逐词时间戳以存储每个单词的开始和结束时间，而不是仅存储每个句子的时间。输出文件会变大。
  5. 选择导出格式。点击高级设置…并在输出格式下勾选DOCX和PDF。SRT、TXT、Markdown 和 JSON 也会带有标签。请保持勾选 JSON：应用需要使用该 JSON 文件来打开转录查看器，这是最后一步所需的。
  6. 点击“转录”。说话人检测会在转录完成后运行，并增加处理时间。然后从最后结果卡片中打开查看转录。
  7. 将通用标签替换为名称。在查看器中，右键点击说话人列中的单元格，选择重命名 'Speaker 00'（全部）...，输入名称并点击保存更改 (Ctrl+S)。旁边的 Word 和文本文件如果仍与原始转录内容匹配，则会被重建；PDF 不会，因此请在重命名后再次导出。

标签的样式

每个片段以其说话人开始。在 Word 或 PDF 转录文本中，该行是时间戳，说话人加粗，然后是文本。SRT、VTT 和 TXT 将Speaker 00:放在文本前面，ASS 将其保留在自己的名称字段中，而 JSON 将其存储为说话人字段。可共享的网页也会显示它。以下几行是布局的说明，并非实际输出：

[00:00:04]  Speaker 00:  So where do we start?
[00:00:07]  Speaker 01:  With the recording itself.

须知

  • 每个片段一个标签。每个转录片段都会分配给与其检测到的语音重叠最多的说话人。如果两个人在一个片段内说话，或者互相抢话，整个片段只会带有一个标签。没有检测到语音重叠的片段则没有标签。
  • 修复单行。重命名会立即更改带有该标签的所有行。查看器无法更改单行的说话人，因此请在导出的 Word 或文本文件中手动修复单行。
  • 通用名称。标签是编号的，这些编号在一个文件内是稳定的，但在不同文件之间并不稳定。
  • 如果数量看起来不对，请将说话人设置为实际人数，而不是保持自动。
  • 离线，无需 Hugging Face 账户。它在你自己的电脑上运行，并在转录之外花费额外时间。
  • 词时间轴。逐词时间戳存储在 JSON 文件中，并用于 VTT 和 ASS 中的卡拉OK式高亮显示。

常见问题

它能帮我标注说话人姓名吗？

默认情况下不能。标签会显示为说话人 00、说话人 01 等。请使用转录查看器中的重命名选项将其更改为姓名。

它能区分多少位说话人？

将 说话人 设为 自动 由应用决定，或者在已知人数时强制指定 2 到 10 之间的数字。

它能区分同时说话的人吗？

不能。交叉对话不会被拆分：一个片段只会获得一个标签，即占据该片段大部分时间的说话人。请通过试听检查这些段落。

哪些导出格式会显示说话人标签？

DOCX、PDF、SRT、VTT、TXT、Markdown、ASS、JSON 以及可分享的网页。
