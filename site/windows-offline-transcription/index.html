Free offline Whisper transcription on Windows

Whisper Transcriber Suite turns audio and video files into text and SRT subtitles on Windows 10 or 11 (64-bit). The app is free, and the local Whisper engine works offline once your model is downloaded.

Download for Windows

1. Choose the installer or portable ZIP

  • Installer (.exe). Use this if you want a Start menu shortcut and in-place upgrades. Run the installer, then open the app from the Start menu.
  • Portable ZIP. Use this if you want to run without installing or lack administrator rights. Extract the entire ZIP to a folder, then double-click Run Whisper Transcriber Suite.bat inside it.

Use the official release linked above. If you need help with the Windows first-launch prompt, see the installation guide.

2. Download a Whisper model once

Stay online for your first transcription. In Transcribe, add a short audio or video file, pick an Accuracy level and click Transcribe. The app downloads the selected local model if you do not already have it. Larger models take more disk space.

After that, the same local model works without internet. Choose File → Work offline when you want to block online features. A different model may need another download.

3. Transcribe a batch and save SRT

  1. Open Advanced settings… and check SRT under Output formats. Keep JSON checked if you want to open the transcript in the built-in viewer.
  2. In Transcribe, drop in several audio or video files, or select them together with Browse files….
  3. Click Transcribe and check progress in Transcription Queue. By default, the SRT goes beside the original, such as lecture.mp4 → lecture.srt.

Optional NVIDIA acceleration

A CPU is enough to run Whisper. With a compatible NVIDIA card, open Advanced → Re-detect hardware… and check whether the app selects CUDA. If the driver or libraries are missing, follow the diagnostics. Install GPU support needs internet once to fetch the CUDA components. See Windows troubleshooting.
