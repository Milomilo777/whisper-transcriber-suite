I-transcribe ang isang interview na may mga label ng speaker (sino ang nagsabi ng ano)

Isang libreng desktop app na i-install mo nang minsanan (Windows, macOS, Linux). Ang iyong recording ay pinoproseso sa iyong computer, at walang account na kailangan.

Ipinaghihiwalay ng app ang mga boses at nila-label ang mga ito bilang Speaker 00, Speaker 01, at iba pa. Hindi nito alam kung sino ang kahit sino hanggang hindi mo sila pinapalitan ang pangalan. Magkatulad na mga boses, maikling sagot, magkapatong na pananalita at ingay sa background ay maaaring magdulot ng maling label. Upang magsimula, i-tick ang Tukuyin ang mga speaker sa tab na Transcribe at pindutin ang I-transcribe.

I-download ang libreng app

Bago ka magsimula

Kasama sa Windows at Mac builds ang mga model para sa pag-detect ng speaker. Kumuha ng app mula sa opisyal na page ng GitHub releases lamang; hindi code-signed ang installer, kaya maaaring magbabala ang Windows (More info > Run anyway). Tingnan din ang home page at gabay sa pag-install.

Paano magdagdag ng mga label ng speaker sa isang transcript

  1. Idagdag ang recording. Sa tab na I-transcribe, i-drag ang audio o video file o i-click ang Mag-browse ng file.... Ang link mula sa tab na Mag-download ng Video ay gumagana rin, dahil gumagamit ito ng parehong setting ng I-transcribe.
  2. Piliin ang Wika, o iwanan ito sa Auto.
  3. I-tick ang Tukuyin ang mga speaker. Kung mababasa sa box ang Tukuyin ang mga speaker (hindi available), i-hover ito upang makita kung bakit. Ang picker ng Speakers sa ibaba nito ay mag-o-on: iwanan ito sa Auto, o pumili ng numero mula 2 hanggang 10 upang pilitin nang eksaktong ganoon karaming tao.
  4. Opsyonal: i-tick ang Timestamp kada salita upang i-store ang oras ng simula at pagtatapos para sa bawat salita sa halip na bawat pangungusap lamang. Mas lalaki ang output.
  5. Piliin ang mga format ng export. I-click ang Mga advanced na setting… at i-tick ang DOCX at PDF sa ilalim ng Mga output format. Ang SRT, TXT, Markdown at JSON ay may dalang label din. Panatilihing naka-tick ang JSON: ito ay isang JSON file na ginagamit ng app upang buksan ang transcript viewer, na kailangan mo para sa huling hakbang.
  6. I-click ang I-transcribe. Tumatakbo ang pag-detect ng speaker pagkatapos ng transcription at nagdadagdag ng oras ng pagproseso. Pagkatapos ay buksan ang Tingnan ang transcript mula sa card na Huling resulta.
  7. Palitan ang mga generic na label ng pangalan. Sa viewer, i-right-click ang isang cell sa column na Speaker, piliin ang I-rename ang 'Speaker 00' (kahit saan)..., i-type ang pangalan at i-click ang I-save ang mga pagbabago (Ctrl+S). Ang mga Word at text file sa tabi nito ay na-rebuild kapag tumutugma pa rin ang mga ito sa orihinal na transcript; ang PDF ay hindi, kaya i-export itong muli pagkatapos mag-rename.

Ano ang hitsura ng mga label

Bawat segment ay nagsisimula sa speaker nito. Sa isang Word o PDF transcript, ang linya ay isang timestamp, ang speaker na naka-bold, pagkatapos ay ang teksto. Ang SRT, VTT at TXT ay naglalagay ng Speaker 00: sa harap ng teksto, pinapanatili ito ng ASS sa sarili nitong name field, at ini-store ito ng JSON bilang isang speaker field. Ipinapakita rin ito ng shareable na web page. Ang mga linya sa ibaba ay ilustrasyon ng layout, hindi totoong output:

[00:00:04]  Speaker 00:  So where do we start?
[00:00:07]  Speaker 01:  With the recording itself.

Magandang malaman

  • Isang label kada segment. Bawat segment ng transcript ay nakakakuha ng speaker na ang detected na pananalita ay pinaka-nagkakapatong dito. Kung mag-usap ang dalawang tao sa loob ng isang segment, o magkapatong, ang buong segment ay may isang label lamang. Ang segment na walang detected na pananalitang nagkakapatong dito ay walang nakukuha.
  • Pag-aayos ng isang linya. Ang pagpapalit ng pangalan ay nagbabago sa bawat linya na may label na iyon nang sabay. Walang paraan ang viewer upang baguhin ang speaker ng isang linya, kaya ayusin nang mano-mano ang mga isahang linya sa na-export na Word o text file.
  • Mga generic na pangalan. May numero ang mga label, at ang mga numero ay stable sa loob ng isang file ngunit hindi sa iba't ibang file.
  • Kung maliwanag na mali ang bilang, itakda ang Speakers sa totoong bilang ng mga tao sa halip na iwanan ito sa Auto.
  • Offline, walang account sa Hugging Face. Tumatakbo ito sa sarili mong computer, at tumatagal ng karagdagang oras bukod sa transcription.
  • Timing ng salita. Ang Timestamp kada salita ay ini-store sa JSON file at ginagamit para sa karaoke-style na pag-highlight sa VTT at ASS.

Mga tanong

Pinangangalanan ba nito ang mga nagsasalita para sa akin?

Hindi agad-agad. Ang mga label ay Speaker 00, Speaker 01, at iba pa. Gamitin ang opsyon sa pagpapalit ng pangalan sa panood ng transcript para gawing mga pangalan ang mga ito.

Ilang nagsasalita ang kayang matukoy nito?

Iwanan ang Mga Nagsasalita sa Auto at magdedesisyon ang app, o itakda ang numero mula 2 hanggang 10 kapag alam mo ito.

Pwede ba nitong paghiwalayin ang mga taong sabay nag-uusap?

Hindi. Hindi hinahati ang crosstalk: makakakuha ng isang label ang isang segment, ang nagsasalitang sumasaklaw sa karamihan nito. Suriin ang mga bahaging ito sa pamamagitan ng pakikinig.

Aling mga export ang nagpapakita ng mga label ng nagsasalita?

DOCX, PDF, SRT, VTT, TXT, Markdown, ASS, JSON at ang maibabahaging web page.
