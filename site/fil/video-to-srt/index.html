Paano i-convert ang video sa SRT subtitles nang libre

Isang libreng desktop app na i-install mo nang minsanan (Windows, macOS, Linux). Ang Whisper, ang model ng pag-kilala sa pananalita na nasa loob nito, ay tumatakbo sa iyong computer, kaya sa mga default na engine, hindi naka-upload ang iyong video.

Upang i-convert ang video sa SRT subtitles, buksan ang tab na Transcribe, i-drop ang video o audio file, suriin na naka-tick ang SRT sa ilalim ng Mga advanced na setting at pindutin ang I-transcribe. Sinusulat ng Whisper ang SRT, ang pangkaraniwang format ng subtitle file, sa tabi ng orihinal na file, handa na para sa player, editor, o upload. Para sa isang link, tingnan ang gabay sa YouTube.

Ayaw mag-install? Subukan sa browser mo: isang libreng page na nagta-transcribe ng maikling file (hanggang 10 minuto) sa device mo, walang upload at walang sign-up. Ang app sa ibaba ang bahala sa mas mahahabang file.

Bago ka magsimula

Ang mga download ay nasa home page; ang mga kinakailangan ay nasa gabay sa pag-install. Gamitin lamang ang opisyal na page ng GitHub releases: hindi code-signed ang installer, kaya maaaring magbabala ang Windows sa unang pagbukas (More info > Run anyway).

1. Gumawa ng SRT

  1. Buksan ang tab na I-transcribe at i-drag ang iyong video o audio file patungo sa window, o i-click ang Mag-browse ng file.... Maaari kang pumili ng ilang file nang sabay-sabay.
  2. Itakda ang Wika, o iwan sa Auto para matukoy ito. Mas mabilis ang pagpili mo mismo at maaaring mas tumpak para sa maiikli o maingay na clip. Katabi nito, pinipili ng Katumpakan ang model: Mabilis para sa mabilis na draft, Balanse, o Pinakamahusay para sa pinakamaingat na resulta (mas mabagal). Ang model na pinili mo sa Advanced settings ay lumalabas bilang Custom at hindi ginagalaw.
  3. Opsyonal: buksan ang Higit pang mga opsyon at punan ang Saklaw ng oras (H:MM:SS) para i-transcribe ang bahagi lang ng file.
  4. Piliin ang mga format ng subtitle. I-click ang Mga advanced na setting… at hanapin ang Mga output format. Ang SRT kasama ang JSON ang default. I-tick ang VTT (ang format ng subtitle para sa web) para sa web video, o ASS (may istilong subtitle / karaoke) kung nag-e-style ka ng subtitle sa isang editor. Bawat naka-tick na format ay sinusulat para sa bawat gawain. Panatilihing naka-tick ang JSON: ito ay isang JSON file na ginagamit ng app upang buksan ang transcript viewer.
  5. Opsyonal: sa ilalim ng Higit pang mga opsyon, lagyan ng tick ang Timestamp kada salita para mag-imbak ng simula at dulong oras ng bawat salita; lumalaki ang mga file. Sumusunod pa rin sa buong segment ang mga SRT cue mo, isang cue kada segment ng pagsasalita. Ginagamit ng VTT at ASS ang oras ng salita para sa karaoke-style na highlighting.
  6. I-click ang I-transcribe. Sundan ang gawain sa tab na Pila ng Transcription. Ang subtitle file ay mapupunta sa tabi ng iyong orihinal na may parehong pangalan at bagong extension, halimbawa ang talk.mp4 ay nagiging talk.srt, at ang card na Huling resulta ay may Buksan na button para sa bawat file.

Mga subtitle sa ibang wika

Para sa English na subtitle mula sa hindi English na pagsasalita, buksan ang Higit pang mga opsyon at lagyan ng tick ang Output: salin sa Ingles; magkakaroon ng pangalang .en-translated ang mga file. Naka-off ito bilang default at hindi gumagana sa bawat engine o model. Para sa ibang wika, makakagawa ng bilingual na SRT ang opsyonal na tab na AI Tools sa transcript viewer kapag na-set up mo ang AI layer nito (isang local model na ini-install mo, o online provider na pinili mo); naka-off din ito bilang default.

2. Itama ito (opsyonal)

Buksan ang Tingnan ang transcript mula sa card na Huling resulta (kailangan nito ang JSON output, naka-tick bilang default). Ang Find & Replace at Alisin ang mga filler ay nagbabago sa teksto; para sa pag-edit nang linya-por-linya, gamitin ang anumang subtitle editor. I-right-click ang isang segment at piliin ang I-edit ang timestamp... upang baguhin ang simula at pagtatapos ng segment na iyon; hindi gumagalaw ang iba pang segment.

I-click ang I-save ang mga pagbabago (Ctrl+S): i-save ng app ang transcript, pagkatapos ay i-rebuild ang .srt at iba pang text file sa tabi nito mula sa na-edit na transcript, kapalit ang mga ito. Ang file na binago mo sa ibang lugar ay hindi ginagalaw, at sasabihin ng app na may luma pa ring teksto ito. Hindi kailanman na-rebuild ang isang PDF. Sa Windows, ang Buksan sa Subtitle Edit ay bubukas sa subtitle file sa libreng editor na iyon, na may waveform view para sa fine-tuning ng timing.

3. I-burn ito (opsyonal)

Mula sa link: panatilihin ang mode sa Audio at video, i-tick ang Gumawa ng video na may subtitle at i-click ang I-download. Nagda-download, nag-transcribe at nagdidikit ng subtitles ang app sa isang bagong file na ipinangalan sa video na may -subbed.mp4 sa dulo. Pinapanatili ang download at ang transcript, at ang umiiral na -subbed.mp4 ay hindi kailanman pinapalitan.

Mula sa file na na-transcribe mo na: buksan ang tab na Pila ng Transcription, i-right-click ang tapos na hilera at piliin ang I-burn ang subtitle sa video.... Kailangan nito ng SRT, kaya panatilihing naka-tick ang SRT sa ilalim ng Mga output format. Ang resulta ay isang MP4 na pinaplay ng mga telepono, TV at browser. Abot-kaya ang oras ng re-encoding; nakadepende sa iyong computer kung gaano katagal.

Magandang malaman

  • Timing. Sinusunod ng mga oras ng SRT ang mga segment ng Whisper. Ang Pinuhin ang word timings gamit ang stable-ts (mas mabagal) sa Mga advanced na setting ay isang opsyonal na karagdagang hakbang na nagpapatalas ng timing ng salita; nagda-download ito ng component sa unang pagkakataon.
  • Suriin bago mag-publish. Minamarkahan ng app ang mga paulit-ulit o imbentong linya, ngunit ang mga pangalan at numero ay karapat-dapat pa ring basahin.

Mga tanong

Anong mga format ng subtitle ang sinusulat nito?

SRT, VTT at ASS, kasama ang TSV, TXT, JSON, LRC, Markdown, DOCX at PDF, at ang mga format ng oTranscribe, ELAN, InqScribe at Express Scribe.

Paano ko idadagdag ang SRT sa YouTube o sa isang video editor?

I-upload o i-import ang .srt bilang isang subtitle (caption) file. Sinusulat ito ng app sa tabi ng iyong video, na may parehong pangalan at .srt na wakas.

Naka-upload ba ang aking video?

Hindi, hindi sa mga default na engine. May dalawang cloud engine ngunit nananatiling nakapatay hanggang ikaw mismo ang mag-on nito, at ang File → Gumana nang offline ay humahinto sa lahat ng paggamit ng network.
