Come convertire gratuitamente un video in sottotitoli SRT

Un'app desktop gratuita che installi una sola volta (Windows, macOS, Linux). Whisper, il modello di riconoscimento vocale integrato, viene eseguito sul tuo computer: con i motori predefiniti, quindi, il tuo video non viene caricato online.

Per convertire un video in sottotitoli SRT, apri la scheda Trascrivi, trascina un file video o audio, controlla che SRT sia selezionato in Impostazioni avanzate e premi Trascrivi. Whisper creerà il file SRT, il formato di sottotitoli più comune, accanto al file originale, pronto per qualsiasi riproduttore, programma di montaggio o caricamento online. Per usare un link, consulta la guida per YouTube.

Scarica l'app gratuita

Prima di iniziare

I download sono disponibili nella home page; i requisiti si trovano nella guida all'installazione. Usa esclusivamente la pagina ufficiale delle release su GitHub: il programma di installazione non ha una firma digitale del codice, quindi al primo avvio Windows potrebbe mostrare un avviso (Ulteriori informazioni > Esegui comunque).

1. Crea il file SRT

  1. Apri la scheda Trascrivi e trascina il tuo file video o audio nella finestra, oppure fai clic su Sfoglia file.... Puoi selezionare anche più file contemporaneamente.
  2. Imposta la Lingua, oppure lascia Auto per rilevarla automaticamente. Sceglierla manualmente è più veloce e può offrire maggiore precisione nei filmati brevi o rumorosi.
  3. Facoltativo: compila Intervallo di tempo (H:MM:SS) per trascrivere solo una parte del file.
  4. Scegli i formati dei sottotitoli. Fai clic su Impostazioni avanzate… e cerca Formati di output. L'impostazione predefinita è SRT più JSON. Seleziona VTT (il formato per il web) per i video online, oppure ASS (sottotitoli con stili / karaoke) se formatti i sottotitoli in un editor. Ogni formato selezionato viene generato per ogni attività. Lascia selezionato JSON: è il file JSON utilizzato dall'app per aprire il visualizzatore di trascrizioni.
  5. Facoltativo: seleziona Marche temporali per parola per registrare l'orario di inizio e fine di ogni parola; le dimensioni dei file aumenteranno. I blocchi SRT continueranno comunque a seguire segmenti interi, con una battuta per ogni segmento di parlato. La temporizzazione delle parole viene utilizzata da VTT e ASS per l'evidenziazione in stile karaoke.
  6. Fai clic su Trascrivi. Segui l'avanzamento dell'attività nella scheda Coda di trascrizione. Il file dei sottotitoli verrà salvato accanto all'originale con lo stesso nome e una nuova estensione (ad esempio talk.mp4 diventa talk.srt) e il riquadro Ultimo risultato mostrerà un pulsante Apri per ciascun file.

Sottotitoli in un'altra lingua

Per ottenere sottotitoli in inglese da un parlato in un'altra lingua, seleziona Output: traduzione in inglese; i file riceveranno la desinenza .en-translated nel nome. L'opzione è disattivata per impostazione predefinita e non funziona con tutti i motori o modelli. Per le altre lingue, una scheda facoltativa Strumenti IA nel visualizzatore di trascrizioni può generare un file SRT bilingue dopo aver configurato il modulo IA (un modello locale da installare o un provider online a tua scelta); è disattivata per impostazione predefinita.

2. Correggilo (facoltativo)

Apri Visualizza trascrizione dal riquadro Ultimo risultato (richiede l'output JSON, selezionato per impostazione predefinita). Trova e sostituisci e Rimuovi riempitivi modificano il testo; per correzioni riga per riga puoi usare un qualsiasi editor di sottotitoli. Fai clic con il tasto destro su un segmento e scegli Modifica marca temporale... per cambiare l'inizio e la fine di quel singolo segmento, senza spostare gli altri.

Fai clic su Salva modifiche (Ctrl+S): l'app salva la trascrizione e rigenera i file .srt e gli altri file di testo adiacenti a partire dalla trascrizione modificata, sostituendoli. Se un file è stato modificato altrove non viene toccato, e l'app segnala che contiene ancora il vecchio testo. I file PDF non vengono mai rigenerati. Su Windows, Apri in Subtitle Edit apre il file dei sottotitoli in quell'editor gratuito, dotato di visualizzazione della forma d'onda per regolare con precisione i tempi.

3. Incidili nel video (facoltativo)

Da un link: mantieni la modalità su Audio e video, seleziona Crea video sottotitolato e fai clic su Scarica. L'app scarica, trascrive e imprime i sottotitoli in un nuovo file con lo stesso nome del video e il suffisso -subbed.mp4. Il download e la trascrizione vengono conservati, e un eventuale file -subbed.mp4 già esistente non viene mai sovrascritto.

Da un file già trascritto: apri la scheda Coda di trascrizione, fai clic con il tasto destro sulla riga completata e scegli Incidi i sottotitoli nel video.... Questa operazione richiede un file SRT, quindi assicurati che SRT sia selezionato in Formati di output. Il risultato è un file MP4 compatibile con smartphone, TV e browser. La ricodifica richiede del tempo, la cui durata dipende dalla potenza del tuo computer.

Informazioni utili

  • Sincronizzazione. I tempi dei file SRT seguono i segmenti di Whisper. L'opzione Perfeziona la temporizzazione delle parole con stable-ts (più lento) in Impostazioni avanzate è un passaggio facoltativo aggiuntivo che rende più precisa la scansione temporale delle parole; al primo utilizzo scaricherà un componente necessario.
  • Controlla prima di pubblicare. L'app segnala le righe ripetute o inventate, ma nomi e numeri meritano sempre una rilettura.

Domande frequenti

Quali formati di sottotitoli genera?

SRT, VTT e ASS, oltre a TSV, TXT, JSON, LRC, Markdown, DOCX e PDF, nonché i formati oTranscribe, ELAN, InqScribe ed Express Scribe.

Come faccio ad aggiungere il file SRT su YouTube o in un programma di montaggio video?

Carica o importa il file .srt come file di sottotitoli. L'app lo salva accanto al tuo video, con lo stesso nome e l'estensione .srt.

Il mio video viene caricato online?

No, non con i motori predefiniti. Esistono due motori cloud che tuttavia rimangono disattivati finché non li attivi esplicitamente, e l'opzione File → Lavora offline blocca qualsiasi utilizzo della rete.
