Как это работает

Работает на вашем компьютере. Ваше аудио остаётся у вас.

Транскрипция выполняется на вашем собственном компьютере. Ваше аудио загружается в сеть только в том случае, если вы включите один из двух дополнительных облачных движков, а текст транскрипции покидает устройство, только если вы сами подключите внешнюю модель ИИ.

  1. 01

    Перетащите файл или вставьте ссылку

    Аудио или видео с диска либо всё, что может скачать yt-dlp. Интерфейс на Tk работает в основном процессе и мгновенно ставит задачу в очередь.

  2. 02

    Воркер держит модель в памяти

    Каждая задача выполняется в отдельном долгоживущем подпроцессе, который держит Whisper в памяти и передаёт данные о прогрессе через строки JSON (newline-delimited JSON) — поэтому окно никогда не зависает.

  3. 03

    Транскрипция сохраняется рядом с вашим файлом

    Токен для каждого воркера и сигналы проверки активности (heartbeat) обеспечивают надёжную маршрутизацию и позволяют приложению вовремя обнаружить зависший процесс, а не зависать вместе с ним.

Создано на базе разработанной OpenAI модели распознавания речи Whisper, работает локально через faster-whisper, whisper.cpp или NVIDIA Parakeet, используя yt-dlp и FFmpeg для обработки медиафайлов.

macOS — установка одной командой

Скачивает подходящую сборку для вашего Mac (Apple Silicon на macOS 14+, в остальных случаях Intel через Rosetta), копирует приложение в Applications и открывает его. Файлы, загруженные через curl, не помещаются в карантин, поэтому вам не придётся закрывать предупреждение о «неустановленном разработчике».

A=x64; [ "$(uname -m)" = arm64 ] && [ "$(sw_vers -productVersion | cut -d. -f1)" -ge 14 ] && A=arm64; curl -fL -o /tmp/wts.dmg "https://github.com/Milomilo777/whisper-transcriber-suite/releases/download/v2.2.0/WhisperTranscriberSuite-v2.2.0-macOS-$A.dmg" && hdiutil attach -nobrowse -quiet -mountpoint /tmp/wts-dmg /tmp/wts.dmg && cp -R "/tmp/wts-dmg/Whisper Transcriber Suite.app" /Applications/ && hdiutil detach -quiet /tmp/wts-dmg && rm /tmp/wts.dmg && open "/Applications/Whisper Transcriber Suite.app"

Предпочитаете привычный способ? Откройте .dmg и перетащите приложение в Applications; при первом запуске потребуется нажать правой кнопкой мыши → Открыть (macOS 14 и ранее) или перейти в Системные настройки → Конфиденциальность и безопасность → Всё равно открыть (macOS 15+).

Не готовы устанавливать? Сначала попробуйте короткий файл в браузере. Все релизы с описаниями — на GitHub Releases. Руководство по установке.

Частые вопросы

Часто задаваемые вопросы

Остались вопросы? Спросите в GitHub Discussions.

Бесплатна ли программа Whisper Transcriber Suite?

Да. Приложение лицензировано под BSD-3-Clause, без подписок и поминутной оплаты. Сама модель Whisper скачивается один раз (около 1–3 ГБ) при первом запуске, после чего транскрибация работает без подключения к интернету.

Отправляет ли приложение мое аудио или видео куда-либо?

Нет, по умолчанию — нет. Все стандартные бэкенды — faster-whisper, whisper.cpp, NVIDIA Parakeet — работают локально на вашем компьютере. Два бэкенда подключаются только вручную (облачный бэкенд на базе Gemini-API и Google Cloud Speech-to-Text), и оба остаются выключенными, пока вы сами не включите их в разделе Расширенные настройки → Бэкенд. Статистика использования (без аудио, без имён файлов) по умолчанию включена и может быть отключена в меню Справка → Статистика использования; раз в день приложение проверяет GitHub на наличие новой версии, а пункт Файл → Работать офлайн полностью прекращает работу с сетью.

На каких платформах работает приложение?

Windows, macOS и Linux. Для загрузки доступны установщик для Windows, портативный архив ZIP для Windows и образ DMG для macOS; в Linux приложение запускается из исходного кода.

Какие форматы транскриптов поддерживает приложение?

srt vtt ass tsv txt json lrc md docx pdf, а также oTranscribe, ELAN, InqScribe и Express Scribe.

Может ли приложение определять, кто говорит?

Да — опциональная диаризация спикеров («Определить говорящих») с пословными временными метками и обрезкой по временным интервалам.

Может ли приложение транскрибировать звук с микрофона или системное аудио в реальном времени?

Да, на вкладке «В реальном времени» — звук с микрофона или системное аудио транскрибируются сразу по мере звучания.

Может ли приложение скачивать и транскрибировать онлайн-видео, например с YouTube?

Да, с любого сайта, поддерживаемого yt-dlp, с возможностью автоматической транскрибации после скачивания.

Может ли приложение составить краткую сводку транскрипта, выделить задачи или ответить на вопросы по тексту?

Да, через дополнительную вкладку «Инструменты ИИ» в окне просмотра расшифровки — краткое содержание, задачи, вопросы и ответы, а также посегментный перевод с формированием двуязычного .srt. По умолчанию функция отключена.

Может ли приложение клонировать голос и озвучивать им новый текст?

Да, через дополнительную вкладку «Клонирование голоса» с помощью OmniVoice (Apache-2.0) — полностью на вашем компьютере. По умолчанию функция отключена; её можно включить во время установки, при этом необходимо подтвердить наличие разрешения на клонирование образца голоса.

Чем это отличается от прямого обращения к Whisper API?

По умолчанию модель запускается локально через faster-whisper, поэтому нет поминутной оплаты за API, а аудио не покидает ваш компьютер — если только вы сами явно не выберете один из двух облачных бэкендов.

Могут ли несколько человек в одной локальной сети использовать приложение без установки на каждый компьютер?

Да — режим «Веб / LAN-доступ» превращает этот компьютер в страницу транскрибации, которой могут пользоваться другие устройства в сети.

Что нового в версии 2.2?

Уровни точности заменили выбор движка и модели на вкладке «Транскрибировать»: выберите Быстро, Сбалансированный или Лучший, и приложение подберёт модель под ваш язык и компьютер; новые установки по умолчанию используют Large v3 Turbo. Более редкие параметры собраны в разделе Дополнительные параметры. Для персидского, китайского, японского, немецкого, тайского, шведского и иврита есть модели, обученные именно для этих языков; на вкладке «Веб / LAN-доступ» появился QR-код, чтобы отправить запись с телефона в той же сети Wi-Fi; Windows зеркально отражает окно для персидского, арабского и иврита; аудио на двух языках доступно как экспериментальная функция; форма загрузки стала компактнее. Все 42 языка интерфейса завершены, исправлено 35 ошибок. На сайте также есть страница, которая расшифровывает короткий файл прямо в браузере. В версии 2.1 появились интерфейс на 42 языках, надёжные метки говорящих и более безопасное сохранение; в версии 2.0 — скорость и оставшееся время очереди, видео с субтитрами по ссылке, транскрипты в виде одной офлайн-веб-страницы, проверяемый режим «Работать офлайн» и перевод на английский. Смотрите Что нового в 2.2 и список изменений.

Может ли приложение превратить ссылку на видео в видео с субтитрами?

Да. На вкладке «Скачать видео» отметьте Создать видео с субтитрами: приложение скачает видео, расшифрует его с помощью Whisper и встроит субтитры через ffmpeg, создав файл с именем исходного видео и -subbed.mp4. Исходная загрузка и расшифровка сохраняются, а существующий -subbed.mp4 никогда не перезаписывается.

Можно ли полностью отключить доступ приложения к сети?

Да. Пункт Файл → Работать офлайн отключает проверку обновлений, статистику использования, загрузку моделей и обращение к удалённым провайдерам ИИ. Пока этот режим включён, строка в нижней части окна показывает, есть ли открытые соединения, а кнопка Проверить офлайн сейчас подтверждает отклонение тестовых подключений. Когда он выключен, приложение обращается к сети только для проверки онлайн-настроек при запуске, ежедневной проверки обновлений, статистики использования (которую можно отключить в меню Справка → Статистика использования) и для начатых вами загрузок.
