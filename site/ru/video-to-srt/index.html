Как бесплатно преобразовать видео в субтитры SRT

Бесплатное десктопное приложение, которое достаточно установить один раз (Windows, macOS, Linux). Модель распознавания речи Whisper работает прямо на вашем компьютере, поэтому при использовании движков по умолчанию видео никуда не отправляется.

Чтобы преобразовать видео в субтитры SRT, откройте вкладку «Транскрибировать», перетащите видео- или аудиофайл, убедитесь, что в разделе «Расширенные настройки» отмечен пункт SRT, и нажмите «Транскрибировать». Whisper сохранит файл SRT — популярный формат субтитров — рядом с исходным файлом: субтитры сразу готовы для плеера, видеоредактора или загрузки на сайт. Если у вас ссылка, см. руководство по YouTube.

Не хотите устанавливать? Попробуйте в браузере: бесплатная страница расшифровывает короткий файл (до 10 минут) на вашем устройстве, без загрузки на сервер и без регистрации. Приложение ниже справляется с более длинными файлами.

Перед началом работы

Файлы для загрузки находятся на главной странице, а требования — в инструкции по установке. Скачивайте приложение только с официальной страницы релизов на GitHub: у установщика нет цифровой подписи, поэтому Windows может выдать предупреждение при первом запуске (Подробнее > Выполнить в любом случае).

1. Создайте SRT

  1. Откройте вкладку «Транскрибировать» и перетащите видео- или аудиофайл в окно либо нажмите Выбрать файлы.... Можно выбрать сразу несколько файлов.
  2. Выберите язык или оставьте Авто, чтобы приложение определило его само. Если выбрать язык вручную, будет быстрее и часто точнее для коротких или шумных записей. Рядом Точность определяет модель: Быстро для чернового варианта, Сбалансированный или Лучший для самого тщательного (но медленного) результата. Модель, выбранная в разделе Расширенные настройки, отображается как Пользовательская и остаётся без изменений.
  3. По желанию: откройте Дополнительные параметры и укажите Временной диапазон (H:MM:SS), чтобы расшифровать только часть файла.
  4. Выберите форматы субтитров. Нажмите Расширенные настройки… и найдите Выходные форматы. По умолчанию выбраны SRT и JSON. Отметьте VTT (формат веб-субтитров) для интернет-видео или ASS (стилизованные субтитры / караоке), если вы оформляете субтитры в редакторе. Для каждой задачи сохраняются все отмеченные форматы. Не снимайте отметку с JSON: этот JSON-файл используется приложением для открытия средства просмотра расшифровки.
  5. По желанию: в разделе Дополнительные параметры отметьте Метки времени для каждого слова, чтобы сохранялось время начала и конца каждого слова; файлы станут больше. Фрагменты SRT по-прежнему соответствуют целым отрезкам речи, один фрагмент на отрезок. Время слов используют VTT и ASS для подсветки в стиле караоке.
  6. Нажмите «Транскрибировать». Следите за выполнением задачи на вкладке Очередь транскрипции. Файл субтитров сохранится рядом с исходным с тем же именем и новым расширением (например, talk.mp4 превратится в talk.srt), а на карточке Последний результат появится кнопка Открыть для каждого файла.

Субтитры на другом языке

Чтобы получить английские субтитры к речи на другом языке, откройте Дополнительные параметры и отметьте Результат: перевод на английский; к имени файлов добавится .en-translated. По умолчанию функция выключена и работает не со всеми движками и моделями. Для других языков вкладка «Инструменты ИИ» (необязательная) в просмотре транскрипта может создать двуязычный SRT после настройки её слоя ИИ (локальная модель, которую вы установите, или онлайн-сервис на ваш выбор); по умолчанию она выключена.

2. Отредактируйте результат (необязательно)

Откройте пункт Просмотреть расшифровку на карточке Последний результат (для этого требуется формат JSON, отмеченный по умолчанию). Функции Найти и заменить и Удалить слова-паразиты изменяют текст; построчное редактирование можно выполнить в любом редакторе субтитров. Щелкните правой кнопкой мыши по сегменту и выберите Изменить метку времени..., чтобы скорректировать начало и конец только этого сегмента; остальные сегменты останутся без изменений.

Нажмите Сохранить изменения (Ctrl+S): приложение сохранит расшифровку, а затем заново создаст .srt и другие текстовые файлы рядом с ней на основе отредактированного текста, заменив их. Файл, измененный в другой программе, затронут не будет, и приложение предупредит, что в нем остался старый текст. PDF никогда не пересоздается. В Windows кнопка Открыть в Subtitle Edit открывает файл субтитров в этом бесплатном редакторе, где есть отображение звуковой волны для точной настройки тайминга.

3. Вшейте субтитры в видео (необязательно)

По ссылке: оставьте режим Аудио и видео, отметьте пункт Создать видео с субтитрами и нажмите Скачать. Приложение скачает файл, транскрибирует речь и наложит субтитры в новый файл с исходным названием и суффиксом -subbed.mp4 в конце. Скачанное видео и расшифровка сохраняются, а существующий файл -subbed.mp4 никогда не перезаписывается.

Для уже транскрибированного файла: откройте вкладку Очередь транскрипции, щелкните правой кнопкой мыши по завершенной строке и выберите Вшить субтитры в видео.... Для этого требуется формат SRT, поэтому не снимайте отметку с SRT в разделе «Выходные форматы». В результате получится файл MP4, который воспроизводится на смартфонах, телевизорах и в браузерах. Перекодирование займет некоторое время; его длительность зависит от вашего компьютера.

Полезно знать

  • Тайминг. Временные метки SRT соответствуют сегментам Whisper. Опция Уточнить тайминг слов с помощью stable-ts (медленнее) в разделе «Расширенные настройки» — это дополнительный шаг, повышающий точность тайминга слов; при первом запуске она скачивает необходимый компонент.
  • Проверьте перед публикацией. Приложение помечает повторяющиеся или выдуманные строки, но имена и числа всё же стоит перепроверить.

Вопросы

Какие форматы субтитров создает приложение?

SRT, VTT и ASS, а также TSV, TXT, JSON, LRC, Markdown, DOCX и PDF, плюс форматы oTranscribe, ELAN, InqScribe и Express Scribe.

Как добавить SRT на YouTube или в видеоредактор?

Загрузите или импортируйте .srt как файл субтитров. Приложение сохраняет его рядом с вашим видео с тем же именем и расширением .srt.

Загружается ли мое видео в сеть?

Нет, при использовании движков по умолчанию — нет. Существуют два облачных движка, но они отключены, пока вы сами их не включите, а режим Файл → Работать офлайн полностью отключает использование сети.
