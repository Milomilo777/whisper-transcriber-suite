Транскрибируйте видео с YouTube в текст — бесплатно и офлайн

Бесплатное приложение для компьютера, которое вы устанавливаете один раз (Windows, macOS, Linux). Для скачивания видео требуется интернет, а сама транскрипция выполняется на вашем компьютере.

Чтобы превратить видео с YouTube в текст, вставьте ссылку на вкладке «Скачать видео», выберите текстовый формат, отметьте «Транскрибировать после загрузки» и нажмите «Скачать». Приложение скачивает видео с помощью открытого загрузчика yt-dlp, транскрибирует его моделью распознавания речи Whisper прямо на вашем компьютере и сохраняет расшифровку в TXT, DOCX, PDF или SRT.

Перед началом работы

Скачивайте установщик только с официальной страницы релизов на GitHub (ссылка на неё есть на главной странице). У него нет цифровой подписи, поэтому Windows может выдать предупреждение при первом запуске: «Подробнее» > «Выполнить в любом случае». Требования: инструкция по установке.

Как транскрибировать видео с YouTube

  1. Только при первом запуске. В окне «Быстрый старт» будет предложено выбрать язык, а также Быстро или Лучшее качество; модель распознавания речи загружается один раз, при первом использовании.
  2. Откройте вкладку «Скачать видео» и вставьте ссылку на YouTube в URL. Приложение автоматически определит доступные форматы и субтитры.
  3. Выберите режим. Вариант Аудио сохраняет только звук — такой файл меньше и скачивается быстрее, если вам нужна только расшифровка. Вариант Аудио и видео сохраняет и видеоряд.
  4. Необязательно: используйте поле Временной диапазон (необязательно), чтобы скачать и транскрибировать только фрагмент. Формат времени — H:MM:SS, а значение 0:00:00 в обоих полях означает всё видео целиком.
  5. Выберите тип файла перед скачиванием. Перейдите на вкладку Транскрибировать, нажмите Расширенные настройки… и в разделе Выходные форматы отметьте TXT (или DOCX, или PDF). По умолчанию выбраны SRT и JSON — в этом случае вы получите субтитры, а не простой текстовый файл. Оставьте галочку у JSON: этот файл JSON используется приложением для открытия просмотра расшифровки. Выбранные на этой вкладке Язык и модель будут применяться и к загрузкам.
  6. Вернувшись на вкладку «Скачать видео», отметьте «Транскрибировать после загрузки», затем нажмите Скачать.
  7. Следите за ходом выполнения. Строка в таблице будет заполняться, а на вкладке Очередь транскрипции отображаются скорость и оставшееся время. По завершении расшифровка сохранится рядом с исходным файлом, а в карточке Последний результат на вкладке «Транскрибировать» станут доступны действия Открыть, Просмотреть расшифровку и Сохранить страницу для отправки.

Более быстрый способ, если у видео уже есть субтитры

Если у найденного видео уже есть субтитры, под ссылкой появится зелёная строка Субтитры доступны и кнопка Использовать субтитры. Это позволяет пропустить скачивание медиафайла и транскрипцию: приложение просто скачивает субтитры и преобразует их в выбранные форматы. Это занимает считанные секунды вместо минут, однако вы получаете исходные субтитры как есть, а не новую расшифровку Whisper. Если отмечен пункт Транскрибировать после загрузки, приложение уточнит нужный вариант и сможет запомнить выбор.

Другие сайты и видео, требующие входа

Любой сайт, поддерживаемый этим загрузчиком, работает точно так же. Для видео, требующих аккаунта (например, Instagram, Facebook, историй TikTok или роликов на YouTube с возрастными ограничениями), выберите свой браузер в пункте Cookies для входа. Приложение считает сохранённый вход из этого браузера на данном компьютере и использует его только при скачивании с этого сайта — данные никуда больше не отправляются. Это может сработать не для всех видео с ограничениями.

Полезно знать

  • Нет подключения — нет загрузки. Пока включён пункт Файл → Работать офлайн, приложение отклоняет проверку ссылок, поэтому отключите его перед тем, как вставлять ссылку.
  • Для YouTube требуется небольшой помощник. Если рядом со статусом ссылки появится кнопка Установить помощник YouTube, нажмите её один раз. Без этого некоторые или все форматы YouTube могут быть недоступны, а скачивание может завершаться ошибкой. Если скачивание не удаётся из-за устаревшего загрузчика, появится панель Обновить.

Вопросы

Это действительно бесплатно?

Да: бесплатно и с открытым исходным кодом, без аккаунта, без подписки и без поминутной оплаты.

Отправляются ли мои видео или расшифровки куда-либо?

Не с движками по умолчанию: Whisper работает прямо на вашем компьютере, и только скачивание с видеосайта использует сеть. Есть два облачных движка, но они отключены, пока вы сами их не включите.

Можно ли транскрибировать видео без субтитров или на другом языке?

Да. Whisper слушает само аудио, поэтому субтитры не нужны. Выберите звучащий Язык или оставьте значение Авто. Опция Результат: перевод на английский преобразует речь на других языках в английский текст; она отключена по умолчанию и работает не со всеми движками или моделями.

Можно ли транскрибировать только часть длинного видео?

Да. Заполните поле Временной диапазон (необязательно) на вкладке «Скачать видео», указав время начала и окончания в формате H:MM:SS. Будет скачан только этот фрагмент, и он будет транскрибирован, если вы отметили «Транскрибировать после загрузки».

Можно ли вставить плейлист целиком?

Нет. Каждая задача рассчитана на одно видео. Ссылка, скопированная из плейлиста, скачивает только это видео, а не весь список.
